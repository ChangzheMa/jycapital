## 上传方式

1. 拉取远程仓库，进入选定运行的子目录。
2. 将该子目录内文件放在平台同一目录，保留原文件名。
3. 选择该目录唯一的 `v1-submission.ipynb`，并附目录中的脚本、模型、配置和依赖文件。

只选择一个运行的子目录，不将仓库其他 Notebook 一并提交。平台附件选择方式以实际界面为准。

## 文件完整性

各目录的 `submission-manifest.json` 记录来源运行和逐文件 SHA-256。根目录 `.gitattributes` 保持 `submissions/` 文件的原始字节，避免 Git 换行转换导致哈希变化。冻结材料不直接修改模型或推理代码，新模型应从对应运行另行导出。

训练过程记录与缓存保留在本地 `outputs/runs/`。提交目录不包含行情、预测答案、凭据或本地 `dai.py`。
