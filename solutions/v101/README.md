# v101：多频 Patch Transformer

[文档目录](../../docs/README.md) · [三个研究家族](../../docs/research-branches.md) · [代码父版本 v9](../v9/README.md) · [模型](v101_model.py) · [模型配置](model-config.json)

v10x 注意力研究家族的首版，以 v9 为代码父版本。研究假设是让不同历史片段在编码阶段按内容交互，改善长窗口利用方式。已完成月内 FP32 迁移到全局 FP16 的运行 `v101-global-fp16-migrated-s42`，冻结结果与平台材料见下文；该结果不代表从头全局训练。

## 主干

| 分支 | 原始窗口 | patch 长度 | patch 数量 |
| --- | ---: | ---: | ---: |
| 1 分钟 | 480 | 8 | 60 |
| 5 分钟 | 240 | 4 | 60 |
| 30 分钟 | 160 | 4 | 40 |

每个 patch 按时间、通道顺序展开全部 75 通道，经 Linear 投影到 96 维。每路加入独立的可学习 CLS 和位置编码，使用两层 Pre-LayerNorm Transformer，4 个注意力头，前馈宽度 192，Dropout 0.1。位置参数按固定交易日槽位学习；所有已知历史可双向交互。每路取归一化后的 CLS，三路拼接八维预测时钟，经 `Linear(296,256) → GELU → Dropout(0.1) → Linear(256,1)` 输出。

总参数 **656,993**。没有时序卷积或全窗口大展平投影。注意力使用 PyTorch math SDPA 后端，确保既有确定性训练要求下无需依赖 FlashAttention 反向路径。

预测截点之后的数值先清零；部分可用 patch 仍保留已知 Bar，全未来 patch 不作为 key/value。历史缺失 patch 保留位置及缺失标志，CLS 始终可用，避免全空历史产生全掩码注意力。因果性、训练控制、比较局限和检查入口见[研究家族说明](../../docs/research-branches.md)。

## 全量随机训练模式

当前默认配置采用[全量 FP16 常驻缓存与全局 shuffle](../../docs/resident-training.md)：基础行情按股票／交易日去重，CPU 缓存与传输使用 FP16，有限极值通过稀疏 FP32 记录恢复，双缓冲预取下一批。label、损失、batch 大小和选模规则保持原定义；验证／推理采用相同输入舍入，验证数据按有限交易日块加载。

原月内 FP32 配置保存在 [model-config-monthly.json](model-config-monthly.json)。既有月内运行只代表其冻结代码和配置，不能直接切换模式续跑。缓存容量估算、构建命令、内存预算和完整验证范围见上面的统一说明。

保留旧训练成果时，使用[显式迁移入口](../../docs/resident-training.md#从旧月内运行显式迁移-v101)在独立 run 下继承 `last.pt` 的完整状态。先按旧游标重建本轮剩余键集合，只对剩余样本使用新模式；旧最佳权重在新输入精度下复核验证基线。迁移保留累计 epoch 和早停计数，来源运行保持中断状态且只读。

## 后续使用

目录内包含独立预处理、切窗、训练、原始行情推理、文本张量和复现模块，不导入其他方案。沿用 v9 的窗口、字段和监督定义，采样及存储精度按当前配置；LayerNorm、Dropout、容量和汇总方式作为本主干的一部分适配。`parent_solution_id=v9`，父 run 为空。

新建从头全局训练时使用以下命令；本次平台导出没有重新训练：

```powershell
.venv-training/Scripts/python.exe -u solutions/v101/v101_train.py --training-run outputs/preprocessing/v2-20261010 --holdout-run outputs/preprocessing/v2-holdout-20261011 --run-dir outputs/runs/v101-global-fp16-s42 --training-confirmed
```

原始行情入口为 [v101_predict.py](v101_predict.py)，与训练共用 [WindowBlock](v101_data.py)。独立预处理使用 `v101_prepare.py`、`v101_apply.py`；协议、恢复、评估和文本附件约定见[开发约定](../../docs/development.md)。

## 冻结结果与平台材料

依据 2026-10-20（UTC+08:00）的本地运行记录，seed=42，第 13 轮按验证 IC 选中，累计 21 轮后动态早停。训练先继承 `v101-patch-transformer-s42` 的月内 FP32 状态，在第 11 轮剩余样本处迁移为全局 FP16 输入；原月内运行保持中断状态。

| 参照角色／方案 | 验证 IC | 验证 Rank IC | 测试 IC | 测试 Rank IC |
| --- | ---: | ---: | ---: | ---: |
| 本次 v101 | 0.076741 | 0.079479 | 0.082303 | 0.083960 |
| 本地验证最优 v7e | 0.076757 | 0.072320 | 0.079773 | 0.074215 |
| 代码父版本对照 v9 | 0.067835 | 0.067583 | 0.077534 | 0.075617 |

三个运行的验证／测试全局及最低截面覆盖率均为 100%，IC 未定义截面为 0。v101 相对 v7e 的验证 IC 差为 **-0.000015919**，测试 IC 差为 **+0.002529856**；按默认验证 IC 规则未晋级。本次按用户明确要求导出为平台测试材料，不改变晋级判定。v9 仅为代码父版本对照，没有继承其权重；平台已有公榜分尚缺可信 run／权重绑定，未确定平台最优。

相对 v7e，验证 IC 在 3／6 个月改善，测试 IC 在 5／6 个月改善，但 2024-09 测试 IC 差为 -0.015471。测试 IC IR 从 0.720469 降至 0.655178，Rank IC IR 从 0.723875 降至 0.715830；原始标签 MSE／MAE 也上升。输出是标准化目标单位，未校准为原始收益。只有一个种子，未作显著性检验；测试期为已观察的研究区间。完整逐月差值、指标和资源记录见[冻结摘要](../../experiments/v101-patch-transformer.json)。

上传文件与平台状态见[提交索引](../../submissions/README.md)，权重、源码与独立推理验证范围见[提交清单](../../experiments/v101-global-fp16-migrated-s42-submission.json)。附件内嵌冻结的训练依赖和推理源码；复现入口从头训练当前配置，不重放历史迁移轨迹，不保证重新得到相同权重。本次导出保留已选权重与 FP16 输入舍入语义，平台运行及官方评分仍待用户提交后确认。

本地 PyTorch 2.11.0+cu130／RTX 4080、`dai` 兼容层下，独立两文件推理通过 2024-01-02—01-05 的 32,000 条和 2024-12-30—12-31 的 16,000 条完整股票池键验证。与冻结评估预测的最大绝对差分别为 1.53e-7、3.87e-7，满足既定 `atol=2e-7, rtol=1e-4`；日期、股票代码及 `float64` 因子类型正确，值有限且键唯一。94 个权重张量按 dtype、形状和字节精确恢复，21 份训练源码／配置恢复后可独立导入训练器；没有重新执行训练。
