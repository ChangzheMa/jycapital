# v2501：同日后续收益标签的密集监督

v250x 新系列首版，run 为 `v2501-future-returns-s42`，直接父版和设计时本地最优均为 v1601。保留原75通道、完整三频GRU历史与主预测，新增训练专用的后续收益头。从seed42重新初始化，共 **2,570,193参数**，其中新增头 **51,201参数**；不继承父权重。正式验证／测试IC为 **0.106972／0.118160**，超过父版但低于随后完成的v2401，不默认导出平台材料。

[研究依据](../../docs/dense-return-supervision-research-20261023.md)结合已完成负结果与近期论文：v2101数量辅助学到了状态，却没有提高收益IC。本版用已有收益任务自身的后续标签组织监督，不复制数量任务、标签后验或外部模型。

## 标签与模型

每个股票日保持八个原始预测时点。主预测及原Huber／排名／专家／路由损失完整保留。对于查询时点 \(q\)，辅助头分别预测同日严格后续时点 \(k>q\) 的原标准化主标签，共28种时点组合。查询必须是当时的股票池成员，后续标签缺失只屏蔽对应损失；当前主标签缺失但查询成员存在时，仍可使用合法后续监督。

所有目标直接来自已提供的 `vwap_return` 及父版已有标准化，不重新计算、反推或合并收益，不读取exposure，也不引入跨日目标。按[训练覆盖检查](../../experiments/future-label-coverage-20261023.json)，现有967,872个有效股票日可提供 **27,100,313个辅助监督对**。它们是原标签与不同历史前缀的配对，不是新增独立样本。

辅助头读取查询的384维当前表示，通过128维投影，并加入目标时钟和相隔时点数的可学习嵌入，经GELU／Dropout和线性层输出预测。它只读取查询状态，不读取目标时点的状态或真实标签。28个辅助输出在完整股票日计算中一次生成，历史编码仍共享。

设 \(A_{i,q}\) 为股票 \(i\) 在查询 \(q\) 具有有效标签的同日后续时点集合。对于非空集合，辅助查询损失为：

\[
\ell_{i,q}=\frac{1}{|A_{i,q}|}\sum_{k\in A_{i,q}}
\operatorname{Huber}_{2}(\widehat y_{i,q,k},y_{i,k}).
\]

再按原日期权重 \(w_i\) 对具有辅助监督的查询平均得到 \(L_{\mathrm{future}}\)。总损失为：

\[
L=L_{\mathrm{parent}}+0.5L_{\mathrm{future}}.
\]

这平均的是各标签的独立损失，不是合并标签。每个查询先归一化，避免仅因早时点有更多后续标签而增加其辅助总权重。0.5是单次试验预设，不做权重扫描。原主损失保留并不保证辅助梯度有益，需由正式IC判断。

## 推理、数据与成本

正式推理只执行原主预测，**不会调用辅助头**；[默认入口](v2501_predict.py)与[fast入口](v2501_predict_fast.py)相同。新增头保存在完整训练权重中以便复现，不参与平台前向。初始化时父参数与主预测逐值一致；这是实现核对，训练后的主权重会因联合目标发生变化。

[缓存兼容性](../../experiments/v2501-input-cache-compatibility.json)确认训练／验证／测试仍复用 `c760f388…`、`b51e456d…`、`749e20cf…`。原主标签与排名数组保持不变，按批增加一个成员标志，再在损失函数中按28个固定组合配对，不新增全量行情或目标数组。

训练／推理为64／128股票日，主机预留 **2GiB**。一次前向和一次反向即可计算全部损失，不使用两次梯度提取；主路径参数和推理计算保持父版结构。默认规模CPU预检使用2个训练、4个推理股票日，三个优化步约 **0.302／0.275／0.277秒**，输出32个有限FP32分数。GPU默认批量及实际训练时间由训练session确认，CPU数据不能外推平台速度。

每个候选只安排一次正式训练，继续使用原验证IC选模及动态早停，再冻结评估测试。辅助指标下降不构成晋级；完整结果须与v1601比较所有月份和时点，报告距双集IC0.25的差距，改善后才生成平台材料。
