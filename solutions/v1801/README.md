# v1801：盘前原始序列与交易阶段条件预测

v180x 系列首版，直接父版为已完成的 v1102，run 为 `v1801-preopen-phase-s42`。从头初始化、seed 42，共 **2,956,338** 个可训练参数，比父版增加 **437,346** 个。已完成 CPU 实现验证，正式训练和双集结果由训练 session 产生；本版尚无收益改善或平台评分结论。

[研究依据](../../docs/session-input-research-20261022.md)来自实际信息覆盖缺口：近期模型在 09:30 较弱，现有规则网格没有纳入已提供的 09:16—09:25 行情，而这些记录已在原预处理文件中保留。相关集合竞价论文只支持机制和局限判断，不提供本项目收益保证。v1201、v1301、v1501 的阴性结果不支持继续默认扩大辅助损失或市场交互，因此本版保留父版训练目标，检验新增盘前信息与可学习读出的整体效果。

## 模型与数据

| 部分 | 设计 |
| --- | --- |
| 原短期主干 | 保留 v1102 三频结构编码 GRU、75 通道、480／288／168 根规则 Bar、四分支预测与时钟条件融合 |
| 盘前输入 | 当前日及前一交易日各十根 1 分钟 Bar，时间固定为 09:16—09:25；沿用原 z/c 数值和三个有效性标志，形状为 `[股票日, 75, 20]` |
| 盘前逐 Bar 表示 | 独立字段结构投影到 96 维，十个位置编码，一层四头注意力；缺失位置显式掩码，不人工构造竞价不平衡或隔夜收益 |
| 跨日状态 | 每日十个状态投影成日表示，两个日表示经过两层注意力；当前分钟状态结合可学习的跨日背景 |
| 时点条件读出 | 历史日状态与当前十个分钟状态组成 11 个记忆位置；父版含时钟信息的 384 维表示分别读取，结果以残差加入预测头前 |
| 初始化与缺失 | 新输出投影初始化为零，残差尺度初值 0.1；全部盘前输入缺失时残差明确为零，仍输出原股票池全部预测 |
| 训练 | 保留父版 Huber、排名辅助、多分支分配、时间权重和 EMA；64 股票日批量，按验证 IC 选模，统一动态早停 |
| 推理 | 128 股票日批量；盘前编码与短期前缀均每股票日计算一次，为八个预测时点共享 |

默认参数及源文件见 [model-config.json](model-config.json)、[盘前编码器](v1801_preopen_model.py)。相同 seed 下父主干初始参数和初始推理输出逐值一致；增加模块会改变后续梯度和随机数消费，不能声称训练轨迹不变。盘前序列与已有最长 20 日的常规行情背景共同学习，不按已观察表现手工只替换开盘输出。

全部盘前槽位均早于最早的 09:30 预测。当天后续 Bar 不用于补齐缺失，也不能进入该时点的输入；历史不足时保留零填充和有效性标志。成交量为零不自动使其他有效字段无效。直接使用已提供的 `vwap_return` 及父版标准化／排名加工，不重算其公式，不使用 exposure，不更换评估股票池或时间划分。

## 缓存、效率与平台 fast

[缓存兼容性和容量记录](../../experiments/v1801-input-cache-compatibility.json)确认短期训练数据配置、打包器和缓存身份不变。目录内 `v1102_resident.py`、`v1102_evaluation_cache.py` 为父版字节一致的兼容模块，必须随冻结执行环境保留；训练短期缓存继续使用 `dbcd47…`，验证／测试继续使用父版 `02d6…`／`00d118…`。

[common/preopen_context.py](../../common/preopen_context.py)从既有 1 分钟预处理文件读取盘前记录，以股票日去重，分别构建训练、验证、测试的 FP32 mmap 旁路。缓存身份绑定输入语义、协议、预处理记录及构建器，不包含网络宽度和损失；读取批次时按父版精度执行 FP16 舍入及 FP32 溢出保留。缓存不读取标签，不改写原短期缓存。

根据真实股票池键计算，三套旁路数值合计约 **3.259 GiB**，另加约 7.6 MiB 映射及其他元数据；64 股票日盘前输入的 CPU 张量约 **0.366 MiB**。构建时对盘前时间范围下推过滤，正式缓存本次尚未构建。已有短期评测缓存若被授权清理，仍需按同一身份重建约 9.85 GiB。容量估计不包含框架、构建缓冲或模型峰值内存。

默认平台入口 [v1801_predict.py](v1801_predict.py)与 [fast 入口](v1801_predict_fast.py)字节一致。从父版已经读取和归一化的 1 分钟行情中取出盘前槽位，滚动保留两个交易日；无需新增远程查询。对包含动态股票池和缺少自身统计股票的合成数据，查询列表与 v1102 fast 完全一致。参考入口独立按样本推理，供小样本一致性核验；没有追加正式行情全区间性能测试，也未声称实测加速倍数。

新增模块会增加计算；父版八轮训练及验证约 118.77 分钟仅作成本参照，不能直接当作本版预计耗时。默认规模 CPU 预检使用 2 个训练股票日和 4 个推理股票日，不能代替 64／128 的 GPU 默认批量预检，后者由训练 session 在模型间隙执行。

## 验证与交接

[readiness](../../experiments/readiness/v1801.json)记录 21 项 CPU 合成检查，完整集合一次运行 31.801 秒。范围包括 [训练目标、共享读出与恢复](../../tests/test_v1801.py)、[月度／全局完整入口](../../tests/test_v1801_entrypoint.py)、[盘前边界及缓存](../../tests/test_v1801_preopen.py)、[平台入口](../../tests/test_v1801_predict.py)。

关键证据是：当前盘前数据能影响 09:30 预测，09:31 以后行情不会影响该时点；盘前输入非零时八时点共享与参考输出一致；无历史时回退父版；本地原生与缓存输入一致；平台完整日、拆日及日内部分请求一致；父版查询复用与动态归一化回退保持。合成训练入口保留 84 个有效训练标签，未因盘前缺失删除样本。这些是实现证据，不代表模型预测能力改善。

一次正式训练，冻结设计参照为父版 v1102 和当时整体本地最优 v1401，完成评估时还须比较届时的本地最优；平台最优仍未精确绑定。正式训练需冻结新公共模块和全部本目录文件，`trainer.preflight_inputs` 会提供额外的 `preopen1m`，不能只传原三频。新增事件 `preopen_context_cache_ready` 的构建和读取时间单独记录。只有完整验证／测试后达到改善条件，才生成 fast 平台材料。
