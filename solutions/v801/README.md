# v801：冻结时序表示与完整截面的残差学习

v80x 系列首版，以本地验证最优 [v501](../v501/README.md) 的 EMA 权重为真实初始化父版本。run 为 `v801-market-context-s42`，一次正式运行已由训练 session 完成；验证 IC 未晋级，不默认导出平台材料。

## 研究假设与依据

v501 已学到有效的个股时序表示，现有主干没有显式学习股票间交互。v801 冻结该主干及原预测头，在同一预测时点的完整股票集合上学习残差；先把计算集中到缺少的关系信息，而不重新训练全部时序参数。它与 v701 的联合扩容、跨频交互和排名辅助头是两个不同研究方向。

[论文审查](../../docs/research-directions-20261021.md)包括 ICML 2026 的市场状态 JEPA、2026-09 的 LiMT 预印本及经典 Set Transformer。相关研究支持低成本集合汇总的机制，但不能证明本项目收益 IC 必然提高。市场状态论文明确报告其表示与收益方向关系较弱；LiMT 使用日频手工因子，迁移局限明显。本版只使用本仓库自己训练的表示，不引入这些论文的因子或外部权重。

## 模型与训练

| 部分 | 设计 |
| --- | --- |
| 冻结部分 | v501 的三个分层 GRU 和原预测头，共 433,409 参数；始终 eval，不更新权重或 dropout |
| 逐股票输入表示 | 三频编码各 96 维及八维时钟，共 296 维；保留 FP32 |
| 集合交互 | 宽度 256、4 个注意力头、16 个学习 token、两个交互块；无股票位置编码或身份嵌入 |
| 信息流 | token 先以完整股票集合为 key/value 汇总，再由各股票读取更新后的 token；每个块带残差 FFN |
| 输出 | 原 v501 分数加新增残差；残差末层权重和偏置置零，因此初始公式恢复父模型 |
| 参数 | 总计 2,129,158，其中 1,695,749 可训练 |
| 批次 | 全局打乱完整 `(date, clock)` 截面，每步一个截面；`batch_size=1000` 仅为默认股票数的预检参考，不用于截断股票池 |
| 优化 | AdamW，学习率 0.0001、weight decay 0.0001、梯度裁剪 1；新模块 dropout 0.1 |
| 选模 | EMA decay=0.9998、首轮 warmup；验证 IC 与现行动态早停；种子 42 |

完整截面内的有效官方收益先作总体标准差归一化得到 \(z\)。训练损失为：

\[
L = \operatorname{Huber}_{\delta=2}(\hat y,z)+0.05\left(1-\operatorname{Pearson}(\hat y,z)\right).
\]

两项都只在标签有效位置计算；上下文仍包含该时点全部股票，不按未来标签筛选股票集合。目标资格沿用原不足／常数截面规则。验证损失单独报告收益 Huber，checkpoint 仍按原始收益的验证 IC 选择。新增模块与训练组织同时改变，结论只能归于完整方案。

冻结部分及新增部分都保存在完整 checkpoint 中。`section_cursor` 表示已经更新的截面数，`sample_cursor` 表示这些截面的名义股票行数；真实有效标签数单独记录。恢复必须保持父模型张量、缓存来源、AdamW、EMA、随机状态和游标一致。

## 表示缓存和 fast 推理

本地先用冻结主干按股票日共享编码，缓存全部实际请求行的 296 维 FP32 表示。训练、验证及最终测试各自首次需要时构建一次，之后只训练／运行新增集合模块。三个完整矩阵按现有行数约 11.48 GB，不含键、目标与元数据；采用磁盘映射按截面读取，不要求全部常驻 RAM。初次构建仍需读原行情缓存，实际端到端耗时待正式运行记录。

缓存身份绑定父模型张量、数据／协议及编码源码，并核对文件内容。构建临时模型不消耗训练随机状态，缓存命中与重建不会改变后续随机序列；缓存发布前检查完整性，Windows 下显式关闭映射。原共享行情缓存不改写。`representation-cache.json` 保存本次三划分的对应关系。

平台不携带表示缓存或离线预测。它从原始行情重新提取表示：股票日编码可以分批，之后收齐同一时点全部股票再做集合交互。因此编码批量不定义市场上下文；不同日期、时点之间不做交互，也不读取标签。动态股票池和缺失时点仅使用请求实际存在的股票。

平台材料若晋级，默认使用此 fast 路径。依据用户的简化约定，复用父版本的输入、归一化和前缀因果证据，加小规模集合／分批检查；不逐版重复长区间对齐与测速。不把结构减少重复计算的判断写成未经测量的加速倍数。

## 检查与复现

[模型与恢复测试](../../tests/test_v801.py)覆盖零残差起点、冻结权重不变、股票顺序等变性、其他股票的实际影响、时点隔离、共享／逐样本编码、编码分批一致性、父张量核验及精确断点恢复。[完整入口测试](../../tests/test_v801_entrypoint.py)用合成 Parquet 走通预处理、三划分缓存、训练、选模、测试及独立逐样本参考，检查缓存复用、随机状态和完整覆盖。这些是实现检查，不是行情收益证据。

正式运行从已登记的本地 v501 `best.pt` 提取主干，核对完整文件和张量指纹。独立复现可通过 `--backbone-artifact` 提供同一父模型的文本张量，指纹必须一致；复现入口从提交包内保存的冻结主干恢复初始化，不依赖私有本机路径。冻结主干仍源于本仓库 v501 的授权数据训练，其来源及训练方法需在最终提交材料中一并保存。

唯一调度清单为 [experiment.json](experiment.json)。GPU 预检由训练 session 在模型间隙执行，覆盖完整截面新增模块及默认股票日批量的冻结编码器。正式结果出来后与 v501、当时本地验证最优比较，超过验证最优且覆盖不退化才默认导出。

## 冻结结果

2026-10-21（UTC+08:00）完成 5 轮训练，最佳为第 1 轮 EMA；完整指标与逐月差值见[比较摘要](../../experiments/v801-gru.json)。父版本与本地验证最优均为 v501，合并比较但保留两个角色。

| 指标 | v501 验证 | v801 验证 | v501 测试 | v801 测试 |
| --- | ---: | ---: | ---: | ---: |
| IC | 0.087199 | 0.086686 | 0.090330 | 0.089235 |
| Rank IC | 0.084019 | 0.082626 | 0.085085 | 0.082859 |
| IC IR | 0.803122 | 0.807456 | 0.771749 | 0.778478 |
| Rank IC IR | 0.899665 | 0.901577 | 0.838800 | 0.851474 |
| 换手代理 | 0.640031 | 0.634420 | 0.641000 | 0.632491 |

IC 在验证／测试分别下降 0.000513／0.001095，Rank IC 分别下降 0.001394／0.002226。IC 双集各仅 1/6 月改善，Rank IC 双集各 0/6 月改善。IR 和[换手代理](../../experiments/v801-signal-diagnostics.json)有改善，但不能换算为平台分，也不替代既定验证 IC 晋级规则。

双集覆盖及最低截面覆盖为 100%，未定义相关截面为零；父模型的 433,409 个参数在最佳、最后原始、最后 EMA 权重中均保持逐张量不变。三划分表示缓存、选模、EMA、完整截面游标和优化器均有核验记录。

整次新增运行 **986 秒，约 16 分 26 秒**；其中训练及逐轮验证 712 秒，训练／验证／测试表示构建和打开分别约 128.5／19.4／22.1 秒。首轮验证包含表示构建，之后每轮验证约 4.6—4.7 秒。这是复用已完成 v501 的增量成本，不包含此前父模型训练；不能与从头训练的时间直接作纯网络加速比。

本次证明了缓存可以降低新增试验成本，尚未证明冻结表示上的跨股票残差有效。训练损失继续下降，而验证 IC 在首轮后持续下降，不支持继续增加头部规模或延长训练。后续可检验小学习率联合适应时序表示与集合模块，配合正则化控制偏移；解冻是否有效仍是待验证假设。当前本地最优仍为 v501。
