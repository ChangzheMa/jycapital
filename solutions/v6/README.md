# v6 提高 TCN 残差块的 Dropout

[文档目录](../../docs/README.md) · [父版本 v5](../v5/README.md) · [模型配置](model-config.json) · [网络图解](../../docs/v6-model.html) · [冻结结果](../../experiments/v6-tcn.json)

运行 `v6-20261015-s42`，父运行 `v5-20261015-s42`，seed=42，选中第 6 轮权重。

## 相对 v5 的变化

仅将四路 TCN 残差块的 Dropout 从 **0.10 提高到 0.35**，融合预测层保持 0.10，分别由 `model.tcn_dropout` 和 `model.dropout` 配置。隐藏通道仍为 160，共 **2,429,505** 个参数。输入、归一化、损失及其他训练设置沿用 v5，权重从头初始化；推理时两类 Dropout 均关闭。

## 结果与局限

相对父版本及训练前本地最优 v5，验证／测试 IC 增加 **0.001379／0.001342**，IC 改善月份为验证 6／6、测试 5／6；两套数据的 IC_IR 均提高。Rank IC 则下降 **0.001581／0.001324**。

验证／测试覆盖均为 100%，无未定义相关系数截面，按验证 IC 判定为本地改善候选。增强 Dropout 减轻了后期训练与验证表现的背离，但过拟合仍存在；两个版本的最佳轮次均为第 6 轮。单种子结果不构成统计显著性证据。

完整指标、逐月差值、权重指纹及验证依据见冻结结果；输出仍为未校准的因子分数。跨版本指标见 [模型结果表](../../docs/README.md#冻结模型结果)。
