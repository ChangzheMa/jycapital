# v1901：完整截面的条件潜在收益结构

v190x 新系列首版，run 为 `v1901-latent-factor-s42`，直接父版与设计时本地最优均为 v1601。目标是检验训练期收益结构能否指导仅依赖历史行情的预测，服务于[双集 IC 0.25 目标](../../docs/ic-target-research-20261023.md)。一次正式训练与双集评测已完成：验证 IC **0.104377**、测试 IC **0.116017**，均略低于 v1601，不生成平台材料。

## 假设与组成

已有普通市场注意力和单股票分布损失没有带来突破；v1801 的盘前方案也没有稳定改善开盘测试 IC。本版把完整截面的标签当作训练后验的观测，用它约束历史先验和跨股票共享结构，同时保留个体直接预测。这里的结构及个体响应均由网络学习，不使用外部先验或 `exposure` 表。

| 部分 | 实现 |
| --- | --- |
| 行情表示 | 保留 v1601 的共同价格坐标、75 通道与三频股票日编码；输入、官方标签和评估协议不变 |
| 初始化 | 精确加载本地 v1601 最佳 EMA 的 127 个张量；新模块 seed 42 初始化，全部参数继续训练 |
| 历史先验 | 384 维个股状态投影到 128 维，16 个可学习查询对同一时点的完整股票池聚合，输出共享潜在变量的均值和标准差 |
| 个体响应 | 每只股票、每个时点学习收益／排名两头对 16 个潜在变量的响应；保留父版原预测作为个体项 |
| 训练后验 | 从行情表示学习截面权重，结合已提供标签的截面标准化值及历史市场表示，估计潜在变量的后验；仅训练时可调用 |
| 预测 | 个体项加个体响应与历史先验均值的内积；初始先验均值为零，初始新增预测项为零 |
| 计算 | 每股票日共享八时点编码，64 股票一块并重计算；共享因子聚合为股票数乘 16，不构造股票数平方的注意力矩阵 |

共 **2,643,973** 个可训练参数，其中父编码器 **2,518,992** 个，新模块 **124,981** 个。该系列改变联合收益学习机制，保留已经有效的编码器和输入；可学习的原始输入归一化仍作为另一研究线，没有在本版中宣称完成。

历史先验为 \(p(z_t\mid X_{\le t})\)，训练后验为 \(q(z_t\mid X_{\le t},u_t)\)。对收益或排名头 \(h\)，预测为：

\[
\widehat u_{i,t}^{(h)}=a_{i,t}^{(h)}+\beta_{i,t}^{(h)\top}\mu_t^p.
\]

\(u_t\) 直接来自已提供的 `vwap_return` 的合法标准化加工；没有从价格重算或反推标签。后验的股票权重由神经网络产生，按有效训练标签掩码后中心化并作范数归一化。无标签股票仍参与历史先验的市场上下文，只有监督和后验标签聚合使用标签有效性掩码。

## 训练与因果边界

训练单位为一个完整交易日，八个时点分别按当时成员集合计算；不把不同日期混成一个截面。直接收益目标为标准化标签的半均方误差，排名辅助为 Huber，另有完整截面的平滑相关性项、后验期望高斯负对数似然和后验到先验的 KL。当前固定权重为：排名 **0.2**、相关性 **0.2**、后验似然 **0.1**、KL **0.1**；相关性分母平滑尺度 **0.05**。各时点的有效标签损失先取均值，再在有效时点间等权。

直接收益误差不按模型预测的不确定性降权。后验似然中的潜在方差项使用解析期望，没有额外随机采样或多次生成推演。上述为归一化的联合训练目标，不将不同归一化权重下的组合误称为原论文完全相同的 ELBO。

父编码器学习率 **0.00003**，新模块 **0.0003**；优化器状态重新初始化。EMA 按实际处理的股票日数折算到每 64 股票日的参考衰减率 0.9999，首轮预热。默认完整市场训练上限 1,200 股票日；训练和推理默认批量预检均覆盖 1,200 股票日，实际编码始终分成 64 股票块。主机内存预留显式为 **2 GiB**。

保留现有验证 IC 选模和统一动态早停，冻结最佳 EMA 后才评估测试集。训练日志单独保存先验相关性、后验相关性、后验似然、KL、潜在标准差和个体响应范数；后验分数只作训练诊断，不能当作可部署效果。新目标、完整日采样、初始化和联合解码同时改变，只评价整体方案，不把收益自动归因于某一组件。

验证、测试和平台入口只调用历史先验。后验方法在 `eval` 模式明确拒绝执行，行情预测接口不接受标签。每个预测时点的聚合只包含当时股票池，未来才出现的成员不参与；所有行情编码仍遵守原始 Bar 截点。未来信息、缺失标签和完整池边界的检查见下文。

## 输入缓存、复现与 fast

[缓存身份核对](../../experiments/v1901-input-cache-compatibility.json)确认训练数据定义、标签变换源码、评测加载器和共享构建器与 v1601 对应，复用同一套缓存：

- 训练：`c760f388…58563b`。
- 验证：`b51e456d…52d800c`。
- 测试：`749e20cf…da5`。

没有新增整套行情输入缓存。该核对只读取父运行清单并计算缓存身份，没有加载或重建全量数组；正式运行仍核对自己的实际输入清单。训练日志和权重按本版独立保存。

父初始化文件 SHA256 为 `24314ff62d4bdd5821be14ebe7a225c5f95d64c06402caee30d99333c37c0d5b`，规范化张量 SHA256 为 `95a92e7734917d8088ca5e961ef4445c6cf7d9b1ce5ac4ddf7aeda6330dfc48a`。正式运行保存 `initialization.json` 和 `initialization-state.pt`，恢复时沿用本版完整模型、优化器、EMA 和随机状态；父版运行不变。

若后续明确要求导出，平台推理只加载本版最终权重。训练复现另需完整父初始化文本张量，可放入独立 JSON 附件以满足单文件 50 MB 限制；[复现入口](v1901_reproduce.py)接受独立初始化载荷。该附件仅在用户显式调用复现时读取，不增加平台预测的父模型加载或计算。本版没有达到默认晋级条件，未生成提交包。

[默认入口](v1901_predict.py)与 [fast 入口](v1901_predict_fast.py)相同。行情编码按股票日共享，先汇总同日各股票的表示，再按完整当时截面计算先验；股票编码块不截断市场上下文。日内部分请求保留所需上下文，输出只回填请求键。[参考入口](v1901_predict_reference.py)独立按每个预测时点重新编码完整股票池，供少量一致性检查。没有增加行情源种类，也没有进行真实行情全区间速度基准，具体平台耗时尚待候选评测。

## 实现验证与结果判定

[readiness](../../experiments/readiness/v1901.json)记录 CPU 合成检查与源码指纹；GPU 默认批量检查由训练 session 在模型间隙执行。检查包括：

- [核心行为](../../tests/test_v1901.py)：父初始化张量对应、非零先验下八时点因果梯度、完整池成员掩码、股票置换及编码分块、后验标签隔离、缺失整时点的有限梯度、解析损失、无标签上下文与精确恢复。
- [完整入口](../../tests/test_v1901_entrypoint.py)：合成 Parquet 预处理、常驻训练、双集评估、缓存与原生输入一致；三个训练日、17 个上下文股票日、16 个有监督股票日、112 个有效标签。
- [平台路径](../../tests/test_v1901_predict.py)：动态股票池、缺少自身统计的股票、非零先验，完整 24 行及部分 9 行请求；fast 与逐时点参考结果一致。
- [复现载荷](../../tests/test_v1901_reproduce.py)：独立文本初始化张量精确恢复，构造的训练命令显式传入该载荷；没有在此检查中启动正式训练。

实际父版权重也已在 CPU 上按全部键和形状严格加载。默认宽度 CPU 预检使用 2 个训练股票日、4 个推理股票日，不能替代 1,200 股票日的 GPU 批量检查。实现通过不构成 IC 改善证据；共享因子可能主要解释不可预测噪声，仍须观察纯历史先验的完整验证和测试结果。

## 冻结结果

[正式汇总](../../experiments/v1901-gru.json)、[时点与目标差距](../../experiments/v1901-ic-target-gap.json)、[信号诊断](../../experiments/v1901-signal-diagnostics.json)均对应最佳第 **1** 轮 EMA；共完成 5 轮、4,850 次更新，按动态早停结束。测试集只评估按验证 IC 选出的冻结权重。双集覆盖率均为 100%，IC 与 Rank IC 无未定义截面。

| 指标 | 验证集 | 测试集 | 相对父版／当前最优 v1601 |
| --- | ---: | ---: | --- |
| IC | 0.104377 | 0.116017 | −0.001149／−0.000243 |
| Rank IC | 0.098343 | 0.100122 | −0.004297／−0.004074 |
| IC IR | 0.873604 | 0.886650 | +0.017944／+0.057327 |
| Rank IC IR | 0.901560 | 0.861451 | −0.019322／+0.029631 |
| 距 0.25 的绝对差距 | 0.145623 | 0.133983 | 未达目标 |

相对 v1601，双集各有 2/6 个月 IC 提高；Rank IC 仅验证 0/6、测试 1/6 个月提高。09:30 的 IC 增加 0.002582／0.010413，但该时点 Rank IC 双集下降，局部改善未转化为整体提升。验证仅 2/8、测试 3/8 个时点 IC 提高；本地换手代理降至 0.649847／0.647446，不能等同于平台换手或官方综合分。已有平台观测尚不能精确绑定本地运行，平台最优参照仍为空。

训练记录中，先验与后验使用相同的平滑相关性定义：第 1 轮分别为 0.146818／0.147206，第 5 轮为 0.157798／0.157844。同期 KL 从 0.000319 降至 0.000122，个体响应范数从 0.116342 降至 0.061274，先验与后验标准差也非常接近。这与新增潜在分支利用较弱相符，未显示“强后验无法转移到先验”的明显差距；缺少分支消融，不能定量认定完全后验塌缩。上述为训练批次原始权重诊断，不能当作正式训练集 IC 或与 EMA 验证 IC 直接比较。

第 1 至 5 轮训练主 MSE 和后验似然损失下降，EMA 验证 IC 却从 0.104377 降至 0.101376。当前证据不支持仅扩大潜在维度、扫描损失权重或延长训练。本次是多项机制组合的单种子试验，不据此否定所有联合收益学习。

新增微调及逐轮验证 **72.214 分钟**，总墙钟 **76.233 分钟**；父 v1601 训练与验证的 **119.399 分钟**需另计。所有父 EMA 张量已精确核对，输入缓存复用，未新增整套行情缓存。源码、优化器与 EMA、输出键、月度指标及早停由训练 session 完成审核；研究 session 核对冻结权重和完整结果后归档。
