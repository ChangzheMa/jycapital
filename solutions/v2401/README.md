# v2401：价格相对位置引导的完整历史读取

v240x 新系列首版，run 为 `v2401-price-memory-s42`，父版与设计时本地最优均为 v1601。从 seed42 重新初始化，保留全部父输入与完整三频历史，增加按当前已知价格定位的历史读取。共 **2,641,743 参数**，比父版增加 **122,751（约4.87%）**。正式双集评估已完成，验证／测试 IC 为 **0.107778／0.119352**，成为新的本地验证 IC 最优，已生成 fast 材料。

[研究依据](../../docs/price-path-research-20261023.md)区分已完成负结果、价格尺度诊断与新假设：v1601行内价格关系有效，但不能直接表达中心自身的时间路径；v2001同时替换数量c并增加其他模块，不能单独归因；v2301缩短历史与MLP的整体组合明显退步。本版保留全部父输入和完整历史，检验不同的直接读取机制。

## 输入和模型

原75通道完整保留：36个z、14个行内价格坐标、22个数量c和三个可用性标志。只补充**原始对数价格中心的FP32数值及一个有效标志**，模型输入为77通道。中心通常是该已闭合Bar的close，缺失时沿用父几何的第一有效价格回退；没有新收益标签。训练仍直接使用已有 `vwap_return` 的原标准化／排名加工，不使用 exposure。

原192维分层GRU、三频融合、四专家和路由均保持。新增路径在每频率执行：

1. 每根Bar的父75通道独立投影为64维key/value，按股票日共享。
2. 各预测时点的原GRU状态形成四头查询；key只能来自其截止位置之前的有效Bar。
3. 每个查询只从已知前缀找最后一个有效价格中心。历史中心与查询中心的差乘100，形成统一对数百分比坐标；可学习小网络结合距离及价格有效性生成注意力偏置，另学习相对交易槽位偏置。
4. 每头读取内容、相对价格位置及有效价格质量，投影回192维，以初值0.1的可学习残差尺度接入原状态，再作父三频融合和预测。

这里的“质量”是注意力在有效价格位置上的权重和，用来区分无价格与零距离，不是额外行情因子。没有预先构造价差、订单不平衡、技术指标、均线或未来收益；相对价格是网络内部的输入坐标。全部历史为空时新增路径为零，原路径保留。

输入窗口仍为1／5／30分钟的480／288／168根Bar，没有截成少量近期片段。八个查询读取全部历史的复杂度随窗口长度线性增长，不执行所有Bar两两注意力，也没有增加八套独立编码器。

## 数据组织、因果性与fast

[缓存身份核对](../../experiments/v2401-input-cache-compatibility.json)确认基础训练、验证、测试仍为 `c760f388…`、`b51e456d…`、`749e20cf…`，基础加载源码原样保留于本目录 `v1601_data.py` 和 `v1601_schema.py`。原全部72个存储数值及稀疏FP32极值恢复保持，尤其不替换盘口数量c。

新的[输入契约](../../common/price_memory_inputs.py)、[缓存接口](../../common/price_memory_resident.py)、[评估接口](../../common/price_memory_evaluation_cache.py)优先引用已验证旧旁路的三份FP32价格中心，检查父数组身份、来源与实际文件。它们不读取旧数量旁路。当前训练／验证／测试中心合计 **1.344 GiB**；如实际加载核验通过，只新增引用清单，不复制这些数组。独立环境缺少可复用中心时，仅从授权原始价格重建所需中心，不要求重建旧数量坐标。

引用清单会依赖来源目录中的价格中心文件，清理资料时须保留被引用文件；本版没有删除任何旧资料。训练常驻数组按真实清单预计 **39.812 GiB**，不含框架、缓冲及进程峰值。训练／推理保持64／128股票日，主机预留 **2 GiB**。

[默认入口](v2401_predict.py)和[fast入口](v2401_predict_fast.py)相同，历史key/value与GRU前缀共享，八时点各自掩码和确定价格参考；[逐时点参考](v2401_predict_reference.py)独立调用对应截点。价格中心来自原查询已经取得的行情，没有新增平台行情表或查询阶段。未来价格、未来有效性或日末中心均不能回写早时点；动态股票池、未知股票与部分日内请求继续按父规则处理。
