# v1201：点预测约束下的 Student-t 分布辅助监督

v120x 收益分布辅助监督系列首版，以已完成的 [v1002](../v1002/README.md#冻结结果与平台材料)为直接父版和冻结设计时的本地最优参照。run 为 `v1201-student-mixture-s42`，seed 42，从头初始化，不继承父版训练后权重。正式训练与双集评估由另一 session 串行执行，实际状态见 [experiment.json](experiment.json)。

## 研究依据

v1002 的验证／测试 IC 为 0.091592／0.097627，时间加权、多分支和当天多频输入组合已获得本地正向结果。本版保持这些设计，联合引入分支尺度、混合似然和分布参与的标签辅助分配，检验分布监督是否能改善最终点预测的 IC。v306 增大 Huber delta 未改善，因此仍保留 delta=2 的主监督。

[文献核验](../../docs/distributional-supervision-research-20261022.md)包括 2026 年金融混合密度、异方差序列预测、UAI 2026 Fisher8，以及 ICLR 2022 对似然优化的分析。部分新论文只核验到出版社记录和摘要；任务、数据和评分与本项目均有差别，不能据此承诺 IC 提升。高预测尺度可能降低似然对难样本的学习力度，所以保留独立于尺度的 Huber 主项。该约束不能证明消除全部优化风险。

## 冻结设计

| 部分 | 设计 |
| --- | --- |
| 输入 | v1002 的 75 通道、1／5／30 分钟因果当天前缀，窗口 480／288／168；同一输入缓存契约 |
| 共享网络 | 每频两级单向 GRU，隐藏宽度 192；两个跨频交互块，融合宽度 384 |
| 分支与路由 | 四个 128 维分支、64 维行情条件路由；每分支输出收益位置、排名、原始尺度 |
| 分布 | Student-t 混合，自由度固定为 4；尺度为 0.2 加 softplus，初始单分支方差为 1 |
| 参数 | **2,419,092**，全部可训练；比 v1002 增加 **516** 个参数 |
| 点监督 | 混合收益 Huber delta=2，混合排名 Huber delta=1、权重 0.2 |
| 分布监督 | 混合负对数似然权重 0.2；分配代价额外包含权重 0.1 的单分支负对数似然 |
| 分配与时间权重 | 近似平衡分配温度 0.25、12 次迭代；分支／路由损失权重 0.1／0.01；训练日历年龄权重半衰期 730 天、下限 0.25 |
| 优化与选择 | AdamW 0.0003、dropout 0.1、EMA 0.9999 与首轮 warmup；验证 IC 选模和统一动态早停 |
| 批量 | 64 股票日训练、128 股票日评估，每日共享八个预测时点的编码 |

精确配置见 [model-config.json](model-config.json)。公共模型输出仍为收益／排名两头；只有训练分支接口包含第三个尺度输出。默认规模、同种子初始化检查确认编码器、跨频块和共享融合层与 v1002 相同；分支末层形状变化会改变后续随机数消耗，不主张分支及路由初值与父版一致。新增尺度行权重置零，偏置初始化为目标尺度的逆 softplus。

## 目标与诊断口径

设有效样本的标准化收益和排名目标为 \(z_i,q_i\)，分支位置、排名和尺度为 \(\mu_{ik},r_{ik},s_{ik}\)，行情路由为 \(\pi_{ik}\)。混合收益与排名分别为分支输出的路由加权均值。令 \(\ell_{ik}\) 为单分支 Student-t 负对数似然，分配代价为

\[
C_{ik}=H_2(\mu_{ik},z_i)+0.2H_1(r_{ik},q_i)+0.1\ell_{ik}.
\]

从代价计算停止梯度的近似平衡分配 \(Q\)，用其加权代价定义分支损失，用其与路由概率的交叉熵定义路由损失。所有样本损失按原时间权重在 batch 有效样本内归一化，总目标为

\[
L=L_{\mathrm{main}}+0.2L_{\mathrm{rank}}+0.1L_{\mathrm{expert}}+0.01L_{\mathrm{router}}+0.2L_{\mathrm{density}}.
\]

其中 \(L_{\mathrm{expert}}\) 已包含代价里的单分支似然，因此这一部分的显式系数乘积为 0.01；它还会改变分配 \(Q\)。混合似然通过 log-sum-exp 计算，全部损失使用 Float64。原始标签、完整截面标准化、有效样本资格和验证／测试口径保持不变。

训练历史额外记录 `train_density_loss`、`train_density_scale_mean`、`train_density_std_mean`、`train_density_scale_floor_fraction`。尺度均值和接近下限的比例先在分支间按路由概率平均，再按 batch 时间权重平均；接近下限指尺度不超过 0.21。混合标准差包含分支内方差和分支均值差异，使用中心化公式避免大数相减。逐轮统计按有效样本数汇总 batch 统计，与父版的训练日志口径一致；它不是将全轮时间权重一次归一化后的均值。

这些诊断来自训练中变化的原始权重，单位为截面标准化目标，不能称为 EMA 留出集校准或原始收益风险。验证仍只计算原点预测指标及主 Huber 损失，不根据似然选模；不同版本总训练损失不直接比较。

## 效率与信息边界

分布计算只作用于共享主干后的四个分支，不增加时序网络。平台继续使用 fast 共享历史和当天前缀，输出混合收益位置，不将尺度用于 factor 缩放，也不在平台计算似然或更新模型。尺度可通过训练梯度影响最终均值，但仅改变已冻结模型的尺度输出行不会改变点预测。

父 v1002 八轮训练及逐轮验证约 98.1 分钟。本版实际 GPU 成本须由训练 session 的默认批量预检和正式运行确认；参数增量小不等于已证明训练同速。[缓存身份检查](../../experiments/v1201-input-cache-compatibility.json)仅读取父版冻结清单与源码，未加载或修改行情数组。正式运行仍核对自己的指纹；旧格式缓存保持只读，评估缓存使用本版本身份。
