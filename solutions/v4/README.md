# v4 完整截面的纯 Pearson IC 训练

[文档目录](../../docs/README.md) · [父版本 v3](../v3/README.md) · [模型配置](model-config.json) · [损失定义](../../docs/v4-ic-loss-plan.md) · [冻结结果](../../experiments/v4-tcn.json)

运行 `v4-20261014-s42`，父运行 `v3-20261014-s42`，seed=42，选中第 6 轮权重。验证／测试相关性超过 v3，按验证 IC 未超过当时的历史最优 v1。

## 相对 v3 的变化

网络及 77 通道输入沿用 v3，共 **1,591,553** 个参数。优化目标改为完整截面的纯 Pearson IC：一次更新使用同一预测时间戳的全部股票，有限官方标签不裁剪、不缩放，截面等权，相关统计使用 FP64。

选择指标改为验证 IC，协议为 [local-v2-ic](../../evaluation/protocols/local-v2-ic.json)。严格最高值保存为最佳权重；超过 `min_delta=1e-5` 的改善重置早停，耐心 12 轮，上限 100 轮。历史版本仍保留原选模结果。

训练前固定结构性退化截面清单并保留全部预测键；非结构性常数预测用相同 RNG 重试 FP32，仍退化则报错。数学定义、退化处理及一致性验证统一见 [IC 损失说明](../../docs/v4-ic-loss-plan.md)。其余优化器、精度及归一化设置见配置和父版本。

## 结果与局限

相对 v3，验证／测试 IC 增加 **0.024819／0.035911**，12 个月的 IC 和 Rank IC 均提高。相对 v1，验证／测试 IC 低 **0.000975／0.010149**，因此未达到本地晋级条件。损失、batch 组织和选模指标同时变化，不单独归因。

验证／测试预测键与 v3 一致，覆盖均为 100%，无未定义相关系数截面。测试 MSE 为 **0.0605474**，明显高于旧回归模型；纯 IC 的输出幅度未校准，`factor = raw_score / 100` 只能解释为因子分数。完整指标及逐月比较见冻结结果，跨版本汇总见 [模型结果表](../../docs/README.md#冻结模型结果)。
