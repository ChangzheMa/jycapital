# v1102：字段结构与时间加权多分支的组合

属于 v110x 字段结构编码系列，以已完成的 [v1101](../v1101/README.md#冻结结果)为直接父版，训练机制取自已完成的 [v1001](../v1001/README.md#冻结结果与平台材料)，本地最优参照为 v1001。run 为 `v1102-structured-temporal-experts-s42`，seed 42，从头初始化，不继承已训练权重。当前只有 CPU 实现检查；正式训练由另一 session 串行调度。

## 组合依据

v1101 相对父 v901 的双集 IC 提高，但验证 IC 0.089995 仍低于 v1001 的 0.090725，换手代理较高。v1001 的时间加权与多分支组合提高 IC、降低换手代理，部分 IR 指标较弱。本版检验将这两个已完成方案合并后的整体效果；两条局部正向证据不保证组合改善。

[最新文献复核](../../docs/structured-input-research-20261022.md)保留了高频分类、订单执行和本项目收益预测的区别。近期 MoE 订单执行预印本的多次训练及设定分解提醒不能把所有收益归因于结构，也不能将其负结果推广到本项目。v1001 路由接近均匀，因此本版不预先宣称分支有明确市场模式分工。正在运行的 v1002 是独立的另一项组合，其未完成成绩不作为本版依据。

## 冻结设计

| 部分 | 设计 |
| --- | --- |
| 输入与字段结构 | 保留 v1101 的 75 通道、三频当天因果前缀、五档盘口与非盘口可学习分支、原始线性残差路径 |
| 时序与跨频 | 单个共享主干；每频两级 GRU 隐藏宽度 192，两个同一时点跨频交互块，融合宽度 384 |
| 预测头 | 由原双头改为四个 128 维双头分支，加 64 维行情条件 softmax 路由；最终混合收益／排名分数 |
| 参数量 | **2,518,992**，全部可训练；比父 v1101 多约 22 万参数 |
| 时间权重 | v1001 的训练日历年龄权重，730 日半衰期、0.25 下限，以固定训练终点为锚，在 batch 有效样本内归一化 |
| 主目标与辅助项 | 收益 Huber delta=2；排名 Huber delta=1、权重 0.2；近似平衡分配温度 0.25、12 次迭代，分支损失权重 0.1、路由交叉熵权重 0.01 |
| 优化和选择 | AdamW 0.0003，dropout 0.1，EMA 0.9999、首轮 warmup；验证 IC 选模和统一动态早停 |
| 批量与推理 | 64 股票日训练、128 股票日评估；平台只输出混合后的收益头，默认 fast |

精确参数见 [model-config.json](model-config.json)。默认规模检查确认同种子从头初始化时，编码主干、跨频块和共享融合层的参数与 v1101 完全一致；原最终预测层被新分支替代，新分支随机初始化。该检查不表示读取了父版本的训练后权重。

字段结构和当天输入保持父版，时间权重、分支监督、损失与预测头构成联合改动。原收益及排名标准化、样本资格、验证／测试区间和覆盖要求不变，只评价整体组合。

## 信息边界与效率

盘口档位交互发生在同一 Bar 内，时间递推仍单向，八个时点各自从历史状态接入当前前缀。行情路由只读取当前表示；标签辅助分配和时间权重仅用于训练损失，不进入推理输入，也不进行在线更新。盘口不完整时保留其余有效字段。

四个预测分支共享同一个时序主干，新增计算集中于低维表示和训练目标。输入槽位仍为 480／288／168，按股票日复用三频编码。父 v1101 的实际成本为约 114.5 分钟训练及逐轮验证，本版的额外成本由 GPU 预检和正式运行确认，不凭参数增量承诺耗时。

[缓存兼容性核验](../../experiments/v1102-input-cache-compatibility.json)确认，使用父 v1101 的冻结数据清单时得到同一训练缓存键；构建模块与 v901／v1101 逐字节一致。核验没有加载或修改行情数组。正式运行仍按自身指纹检查后复用；评估缓存使用自己的身份，不绕过检查。内存预留仍为 8 GiB，评估逐段加载。

## 实现检查与交接

[模型检查](../../tests/test_v1102.py)覆盖字段映射、同 Bar 交互与不完整输入保留，三频逐时点因果性、共享／逐样本预测一致、默认规模共享层初值一致、时间权重隔离、分支目标、缺失标签、精确恢复和缓存身份。[完整入口检查](../../tests/test_v1102_entrypoint.py)使用合成 Parquet，走通月度／全局训练及留出推理，并核对当天粗频数据、时间权重记录和旧缓存保留。

CPU 默认规模预检确认全部参数梯度和输出有限；不代表正式收益或 GPU 吞吐。实际候选状态见 [experiment.json](experiment.json)。每个方案一次正式运行，只有验证 IC 超过可比历史最优且覆盖完整时才默认导出 fast 材料；测试、IR 和换手代价保留报告。
