# v1001：行情条件多分支与训练期时间加权

v100x 训练分布适应系列首版，代码父版本和比较参照为已完成的 [v701](../v701/README.md)，本地验证最优参照为 v501。run 为 `v1001-temporal-experts-s42`，seed 42，从头初始化，不继承父权重。正式训练由训练 session 串行调度；当前只有 CPU 合成实现验证，没有模型成绩或平台材料。

## 研究假设

[近期论文审查](../../docs/research-directions-20261022.md)指出，在线更新、历史误差记忆、价格预测与当前冻结权重的分钟截面收益评测存在条件差异。本版只借鉴潜在多模式关系和训练期分布适应的思路，不复现 TRA 完整算法，也不引用其完整路由成绩作为效果预期。

本地 v701 展示了可接受的共享计算成本，但不同月份、时点的优势并不一致；v801／v802 的当前跨股票集合模块未改善验证 IC。因此改为在单股票时序表示内学习多个预测分支，并用有下限的训练期时间权重减少较早样本对目标的影响。月份差异本身不证明概念漂移，近期数据也不保证更接近未来。本版只检验整体组合，不能把结果单独归因于分支、权重或宽度。

## 冻结设计

| 部分 | 设计 |
| --- | --- |
| 输入、标准化与目标资格 | 与 v701 一致，75 通道、原时间分辨率、固定历史窗口；1 分钟含当天，5／30 分钟仅历史交易日 |
| 共享编码 | 每频两级单向 GRU；隐藏宽度 192，两个跨频交互块；64 股票日共享编码，最多 512 个有效目标 |
| 共享融合 | 三频表示与时点编码融合到 384 维 |
| 预测分支 | 4 个小型 MLP，各有 128 维中间层，输出收益／排名两头 |
| 路由 | 384→64→4 的 MLP，softmax 加权全部分支；只读当前可获得的行情表示和预测时点 |
| 总参数 | 2,418,576，全部可训练 |
| 主监督 | 原收益截面 zscore Huber delta=2；独立排名 zscore Huber delta=1，权重 0.2 |
| 分支辅助监督 | 训练标签生成分支损失矩阵；log-domain Sinkhorn 12 次，温度 0.25；分配停止梯度，列负载近似平衡 |
| 辅助项 | 分配加权的分支损失权重 0.1；路由与分配的交叉熵权重 0.01 |
| 时间权重 | 以训练区间的排他终点为锚，日历半衰期 730 日，下限 0.25；不丢弃较早日期 |
| 训练和选择 | AdamW 学习率 0.0003，dropout 0.1，EMA decay=0.9999、首轮 warmup；验证 IC 选模和统一动态早停 |
| 推理 | 128 股票日共享编码；只输出混合后的收益主头，保持原键和全覆盖 |

完整配置见 [model-config.json](model-config.json)。所有分支属于一次联合训练的单个网络，时序主干仅编码一次；没有为每个分支分别启动训练。

## 时间加权与监督边界

令训练区间排他终点为 \(T\)，样本日期为 \(t_i\)，日历日距离为 \(a_i=T-t_i\)，则

\[
w_i=0.25+0.75\,2^{-a_i/730}.
\]

同一股票日的八个时点共享该日期权重。样本仍按原资格保留，原收益和排名目标的完整截面标准化保持不变；每个 batch 在有效标签样本上按权重和归一化。权重不读取验证／测试日期、收益、未来行情或平台分。训练边界之外的日期直接报错；`stock-day-training.json` 保存日期及权重指纹，并在恢复时核验。

记混合收益／排名预测的损失为 \(L_{\mathrm{main}}\)、\(L_{\mathrm{rank}}\)，第 \(k\) 个分支的相同双头损失为 \(C_{ik}\)，仅在训练损失内部计算分配 \(Q\)。路由概率 \(p_{ik}\) 始终来自行情表示，损失为

\[
L=L_{\mathrm{main}}+0.2L_{\mathrm{rank}}
 +0.1\frac{\sum_i w_i\sum_k Q_{ik}C_{ik}}{\sum_i w_i}
 -0.01\frac{\sum_i w_i\sum_k Q_{ik}\log p_{ik}}{\sum_i w_i}.
\]

分支损失 \(C\) 已包含权重 0.2 的排名项；主损失和排名损失也使用相同的样本权重。有限次 Sinkhorn 只保证近似列平衡，最终每行重新归一化；不把它描述为求得精确最优分配。分配和监督目标从不传给模型推理函数。

逐轮保存训练损失分项、平均路由概率和路由熵，用于识别分支坍缩或近似均匀路由。它们是诊断信息，不替代验证 IC 的选模规则。历史中的训练损失为按样本数汇总的 batch 加权损失；留出集指标仍按原协议等权评估，没有时间加权。

## 计算、检查与复现

继承 v701 的因果股票日 fast 路径；多分支仅作用于编码后的低维表示，不重复切窗或运行时序主干。eval 时共享与逐时点路径等价，09:30 不读取当天未来 Bar，缺失时点只回填实际请求。评估行情段改为串行加载，避免预取两段造成额外主机内存占用；不修改公共缓存或 v901 的独立新输入缓存。

[模型测试](../../tests/test_v1001.py)覆盖双头共享推理、各时点未来梯度隔离、原始目标不变、时间权重与留出集信息隔离、月度／resident 日期映射一致、近似平衡分配、权重梯度比例、无效标签隔离，以及中断恢复后的参数／EMA／AdamW／随机状态和路由诊断一致性。[入口测试](../../tests/test_v1001_entrypoint.py)在临时合成 Parquet 上走通预处理、月度与全局股票日训练、留出评估与逐样本参考推理。

CPU 默认规模预检确认梯度和输出有限；GPU 默认批量、实际吞吐和正式效果由训练 session 检验。预计仍属于单 GPU 可多轮尝试的规模，不能只根据参数量或 v701 的时间比承诺加速。每个候选一次正式训练，不补跑种子。平台材料只在本地晋级后按 fast 逻辑生成；本版推理不更新参数、不读取历史标签记忆，也不使用离线预测文件。
