## 模型与因果边界

保留v2401的全部77通道、480／288／168三频窗口、字段结构投影、价格历史读取、三频融合和收益／排名多分支目标。替换日内及跨日GRU：每频两层192维关联模块，四个head，每head键32维、值48维；每层矩阵状态共6,144个数值，不是额外6,144个可训练权重。日内宽4的因果逐通道卷积处理局部变化，矩阵状态跨历史日连续传递。已知日槽位与日内槽位使用零初始化位置嵌入。

写入先减去同一键在旧状态下的读取，再加入新值；遗忘门控制整体衰减。缺失整根Bar不写入、不衰减，查询读此前最后有效位置；部分缺失沿用父有限值和标志。过去和当前可见窗口一次编码，八时点分别读取前缀，不能看到未来Bar或未来状态。模型权重在平台冻结，状态仅由本次调用的历史行情产生，不保留跨调用样本库，也不读取收益标签。

核心分块实现见[v3001_delta.py](v3001_delta.py)，使用32位置的小型下三角求解和矩阵乘法；全部递推累计为FP32，不依赖Triton、外部预训练或专用CUDA扩展。独立逐步方程仅用于定向检查。隐藏层使用RMS归一化，原始输入尺度和原残差通路保留；多项结构变化只评价整体方案。
