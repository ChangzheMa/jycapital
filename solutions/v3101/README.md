# v3101：因果行情表征预训练与收益微调

[研究审查](../../docs/representation-pretraining-research-20261024.md) · [模型配置](model-config.json) · [候选登记](experiment.json)

本版属于新系列v310x，结构父版为v2401。检验的机制是把行情表征学习与收益监督分成两个阶段，避免在收益训练全过程中混合辅助任务。不是从旧v2401权重续训；种子42重新初始化，整个候选一次正式运行。

使用`jycapital-raw-20261024`新快照及独立预处理，已完成／已启动的旧训练不重跑。仅与同一数据组的完整结果比较；v2401保留为结构来源，不能据跨快照差值宣称本机制改善。

## 模型与两阶段目标

推理网络与v2401相同：77通道，1／5／30分钟窗口480／288／168 Bar，结构化字段投影、分层GRU、三频融合、完整价格历史读取和四个收益专家。参数 **2,641,743**；收益／排名双头、时间权重、专家及路由目标沿用父版。

预训练固定两轮，使用训练股票池中所有股票日的行情和请求存在性，不按标签有效性筛选。每个输入产生两份独立遮挡视图，以0.2概率遮挡一个半小时块；跨频同步，全部值及标志一起置零，未改写底层缓存。八个时点各自保持因果前缀，没有未来窗口目标或新计算的收益标签。

预训练取384维融合表示，时点one-hot输入置零，经384→256→128的训练专用投影计算一致性、方差及协方差目标。方差只在同一时点的股票日batch内计算，协方差先去掉各时点均值，再合并有效样本；不存在的请求不参与统计。至少两个股票日的时点才能参与方差／协方差；不足的batch明确跳过并记录，不根据标签决定跳过。

外部投影 **131,456** 参数，不属于主模型`state_dict`，不进入平台推理。预训练学习率0.0001、权重衰减0.0001、裁剪1，损失权重25／25／1。固定预训练结束后，保留主模型参数，撤去投影和表征目标，重新创建收益AdamW与EMA；收益学习率0.0003，原动态早停和验证IC选模规则不变。

## 数据、效率与恢复

- 所有拟合限制在2020—2023；验证／测试只用于原评估流程，预训练不读取它们。
- 监督目标仍由提供的`vwap_return`标准化／排名得到，不重算标签，不访问exposure。
- 与新快照下v3001的输入配置、基础加载器及目标转换一致；同一来源清单产生相同训练／验证／测试缓存键，见[兼容性证据](../../experiments/v3101-input-cache-compatibility.json)。这是键和语义检查，不代表在训缓存或调度验收已经完成。
- 主机内存预留2GiB。预训练／收益训练batch均64股票日，推理128；两视图增加预训练计算，不新增完整行情／目标数组。固定两轮预训练的实际耗时须在正式记录中单列。
- `pretraining-last.pt`保存主模型、训练投影、优化器、RNG及阶段游标；`pretrained.pt`和`pretraining.json`记录固定阶段完成。恢复时核对数据、配置和权重；已完成预训练只核验，不重复训练。收益阶段继续使用`last.pt`中的原始权重、EMA、AdamW和RNG。

训练仍由监控session串行调度。新数据路径使用[路径解析器](../../scripts/training-data-paths.py)绑定，不套用旧全局常驻缓存参数。设备预检入口检查双视图预训练、收益微调和推理三个阶段；默认GPU批量由监控session在训练间隙执行。

## 实现验证与平台路径

12项CPU检查通过，完整测试耗时50.829秒，涵盖：

- 与v2401相同初始化参数和收益预测；文本参数精确恢复。
- 独立NumPy手算损失、缺失请求及单样本时点；只编码时点仍受到方差惩罚。
- 跨频半小时遮挡、底层数组不变、八时点未来梯度为零。
- 所有标签改成NaN后，预训练成员及顺序仍相同，固定预训练仍可执行。
- 预训练及收益阶段中断恢复后的参数、优化器、RNG精确一致；已完成阶段不重做，变更凭据拒绝恢复。
- BF16预训练有限梯度；月内及全局模式的完整合成Parquet训练、验证、测试入口。
- 动态成员及部分请求的fast／参考推理一致，输出键、有限性及覆盖检查。

另通过默认网络宽度的小批次CPU预检与隔离源码导入：四股票日双视图预训练约1.14—1.26秒／步，两股票日收益微调约0.34—0.38秒／步。这是实现检查，不是正式GPU吞吐或训练时间预测。推理导入不依赖预训练模块、常驻缓存或训练工具；平台继续采用股票日共享fast计算，正式晋级后才导出材料。

正式结果见下节；表征损失下降或实现检查通过本身不构成IC改善证据。遮挡可能丢失有效短期信息；表示也可能学习到与收益无关的股票或波动特征。具体机制与论文适用边界见研究审查。
