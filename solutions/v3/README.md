# v3 两个组完整标志与扩容

[文档目录](../../docs/README.md) · [父版本 v2](../v2/README.md) · [模型配置](model-config.json) · [冻结结果](../../experiments/v3-tcn.json)

运行 `v3-20261014-s42`，父运行 `v2-20261011-s42`，seed=42，选中第 9 轮权重。验证／测试优于 v2，未超过当时的本地验证最优 v1，未导出平台材料。

## 相对 v2 的变化

- 将 72 个逐数值掩码改为非盘口、盘口两个组完整标志，输入由 147 降为 77 通道。组内全部 z/c 有限才置 1，组不完整时仍保留其余有效值；布局及 Bar 有效性见 [字段可用性定义](../../docs/v3-field-validity.md)。
- 分支隐藏通道由 64 扩至 128，融合层宽度由 128 扩至 256；四路向量加时钟后为 `514 → 256 → 1`，共 **1,591,553** 个参数。
- 训练上限由 12 改为 100 轮，早停耐心由 3 改为 12 轮，重置门槛仍为 `min_delta=1e-5`；最佳权重仍取严格最高验证 Rank IC。

字段、归一化、四频窗口、残差结构、Huber 损失及其余训练设置沿用 v2，复用其冻结预处理。以上变量同时改变，只能评价整体方案，不能把改善单独归因于掩码或宽度。

## 结果与局限

相对 v2，验证／测试 Rank IC 增加 **0.013737／0.008114**；相对 v1 仍低 **0.016931／0.026300**。预测键与父版本一致，完整股票池及最低截面覆盖均为 100%，相关系数无未定义截面。

测试 MSE 为 `2.50242e-5`，高于 v2 的 `2.27624e-5` 和零预测参照 `2.20818e-5`；排序改善不代表收益幅度拟合改善。完整指标及逐月差值见冻结结果，跨版本汇总见 [模型结果表](../../docs/README.md#冻结模型结果)。

## 使用

入口为 [v3_prepare.py](v3_prepare.py)、[v3_apply.py](v3_apply.py)、[v3_train.py](v3_train.py) 和 [v3_predict.py](v3_predict.py)，各自使用 v3 模块。训练、恢复及数据目录见 [开发约定](../../docs/development.md#训练入口)。v3 尚无专用导出工具，不能直接使用 v2 导出器。
