# v2701：完整成交字段与日级价格参考

v270x新系列首版，run为`v2701-trade-reference-s42`，直接父版与设计时本地最优为[v2401](../v2401/README.md)。从seed42重新初始化，完整保留父输入、三频GRU和因果价格历史读取，增加原先未使用的成交笔数、前收盘价与复权因子。共 **2,805,333参数**，比父版增加163,590，约6.19%。正式效果待训练session完成双集评估。

## 研究依据与组合假设

[训练期审计与近期论文](../../docs/unused-market-fields-research-20261023.md)确认现有主线遗漏三个有效行情字段。`deal_number`是成交笔数，不等于盘口委托笔数，也不是标签表未来窗口的`num_trades`。样本内`pre_close`和`adjust_factor`为日级常量，参考差异与因子变化同日出现，但未确认完整官方复权公式。

本版联合检验：补充成交过程和日级参考信息，并让它们在时序编码及历史内容投影前与父字段交互，是否改善当前收益预测。原来的价格历史读取、所有z／数量c和完整因果窗口均保留。未默认叠加v2501辅助监督或v2601市场条件，未沿失败版本扫描相邻宽度或训练轮数。

## 输入和计算

父版77通道逐值保持，新增三个FP32值和三个独立有效性标志，总输入83通道。成交笔数有限且非负时取`log1p`，有效零保留；前收盘价、复权因子有限且为正时取对数。新字段没有需要拟合的统计量，父字段继续使用原训练期冻结统计和因果回退规则。字段独立缺失，不清除其他有效输入，也不丢弃预测股票。

网络内的日级价格参考坐标为：

\[
d_t=100\bigl(\log a_t-\log p^{\mathrm{pre}}_t\bigr).
\]

其中\(a_t\)是父版同一已闭合Bar的价格中心，\(p^{\mathrm{pre}}_t\)直接来自该Bar提供的`pre_close`。任一值无效时坐标为零，并提供单独有效标志；不从后一根Bar或当天日末补参考。复权因子仅作为输入，不据此重算原始价格。所有主监督继续使用已提供`vwap_return`的原标准化／排名加工，不读取exposure。

每个频率有两个新增投影：父75维表征、新增三个值、三个标志、日级坐标及其标志，共83维，经128维GELU／Dropout网络投影；一条接入原192维时序输入投影，一条接入原64维历史内容投影。它们在后续非线性和key/value生成前参与计算，所有Bar与八时点共享参数。输出层零初始化，残差尺度初值0.1，因此新模型初始化时父参数和预测精确保持；训练后两条路径均可学习新增字段。

窗口仍为1／5／30分钟的480／288／168根Bar。每根Bar的参考来自自身已知字段，历史与当前前缀共享编码；查询价格历史时仍按每个查询的最近有效闭合Bar定位。09:30没有当日常规Bar，不借用09:31之后才出现的当日字段。

## 数据复用与成本

[输入身份与布局预算](../../experiments/v2701-input-cache-compatibility.json)直接重建基础缓存键，确认训练／验证／测试仍复用`c760f388…`、`b51e456d…`、`749e20cf…`。基础加载代码原样保留为本目录`v1601_data.py`、`v1601_schema.py`；价格中心继续引用已核验的FP32文件，不读取旧数量旁路。

新的[纯输入变换](../../common/trade_reference_inputs.py)、[常驻／流式接口](../../common/trade_reference_resident.py)及[评估接口](../../common/trade_reference_evaluation_cache.py)只另存三份频率各自的三字段FP32数组。训练及两留出区间预计新增数组 **4,328,266,176字节，约4.031GiB**，不复制整套父缓存或预处理Parquet。独立环境缺少可复用价格中心时，只重建必要中心及新字段，平台直接利用原查询取得的三个新增列。

默认64个训练股票日、128个推理股票日，预留 **2GiB**。CPU默认宽度预检使用2／4股票日，三个合成优化步约0.346／0.320／0.317秒；这不是GPU默认批量吞吐或正式训练时间，实际成本由训练session记录。收益损失、排名辅助、专家分配、日期权重、AdamW、EMA及验证IC早停沿用父版，一次正式训练后冻结测试。

## 实现验证与平台路径

[实现记录](../../experiments/readiness/v2701.json)记录15项CPU检查及实际源码指纹：

- [主模型](../../tests/test_v2701.py)：初始化父参数／预测保持、非初始新增投影下八时点fast／参考一致、未来全部字段梯度为零、文本张量与断点原始权重／EMA／AdamW／RNG精确恢复。
- [新增字段](../../tests/test_v2701_reference.py)：有效零成交笔数、独立缺失、父77通道逐值保持、日级参考可手算、新增三字段的有效梯度及CPU BF16有限性。
- [旁路缓存](../../tests/test_v2701_cache.py)：无标签构建、引用旧价格中心但不读数量、原生／常驻／流式一致、预取顺序、父数组及极值保持、重复键和损坏拒绝。
- [完整合成入口](../../tests/test_v2701_entrypoint.py)：月度FP32和全局混合精度训练、选模、验证／测试完整输出及相同主目标。

实现检查不证明收益IC提高。当前只发布训练候选，完整结果应同时对比父版v2401与届时验证最优，报告双集距0.25、月份／时点和资源成本。晋级后才从冻结源与权重生成fast平台附件；没有执行真实平台评测或长区间性能基准。
