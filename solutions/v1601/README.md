# v1601：共同价格坐标与字段结构编码

v160x 输入坐标系列首版，直接父版为已完成的 [v1102](../v1102/README.md#冻结结果)，run 为 `v1601-price-geometry-s42`。从 seed 42 重新初始化，不继承训练后权重。设计时总体最优参照为 v1401，单主干及父版参照为 v1102；平台成绩的本地权重绑定仍未确认。

## 研究问题

[价格结构审计](../../docs/raw-input-research-20261022.md)发现，逐字段 z/c 标准化不直接保留盘口档位及 OHLC 的相对关系，FP16 还会合并部分不同档位。v1102 虽然按字段分组编码，其输入仍是这种坐标。本版给网络提供保留价格相对关系的第二视图，检验输入表达本身的作用。

诊断曾用前日收盘价作为共享中心；本版明确选择**同一已闭合 Bar 的收盘价**，使价格围绕更接近当前观测的中心表达，并减少跨日跳变带来的舍入问题。这是独立的模型设计选择，不把前日中心的审计比例冒充本版已经验证的收益效果。长期状态由原 z 视图保留；数量字段保持原截面表达。

## 输入契约

每频仍为 72 个数值及 3 个有效性标志，窗口为 1／5／30 分钟的 480／288／168 槽位。

| 部分 | 通道 | 规则 |
| --- | ---: | --- |
| 长期视图 | 36 | 原冻结 z，数值不变 |
| 价格结构视图 | 14 | OHLC 与五档买卖价共用当前已闭合 Bar 的价格中心，列名为 `g_*` |
| 数量截面视图 | 22 | 成交量、成交额、挂单量及订单数保留原 c，数值不变 |
| 有效性 | 3 | 原非盘口组完整、盘口组完整、Bar 有值标志，按新数值的有限性生成 |

对于当前 Bar 的有效正价格，价格视图为

\[
g_f=100\bigl(\log p_f-\log a\bigr).
\]

中心 \(a\) 优先取该 Bar 的有效正收盘价。收盘价无效时按配置中的固定字段顺序选择本 Bar 第一个有效正价格；全部无效则价格视图缺失。非正、NaN、Inf 仍是缺失，不填造价格或删除股票。共同单调变换保留同一 Bar 内的大小关系，FP16 仍可能合并极小差异，不承诺完全无误差。

价格中心只用于输入归一化，不构造价差、订单不平衡或技术指标特征；不重算 `vwap_return`，不读取 `exposure`。Bar 结束时点不晚于预测时点才可进入模型，缓存中的未来槽位由既有切窗及网络再次清零。

```mermaid
flowchart LR
    A[既有冻结预处理] --> B[36 路 z 与 22 路数量 c]
    C[原始已闭合 Bar 价格] --> D[14 路共同价格坐标]
    B --> E[按完整键对齐并打包]
    D --> E
    E --> F[字段结构编码与三频共享预测]
```

## 模型与训练

网络与父 v1102 保持相同的 **2,518,992** 个可训练参数：每频两级单向 GRU，宽度 192，字段结构分支、跨频交互、384 维融合、四个 128 维专家与 64 维路由。默认同种子初始化的全部模型张量与父结构逐值相同，保持训练目标、优化器和批量，避免把容量扩张混入本次输入检验。

训练仍用已提供的官方 `vwap_return` 构造完整截面 z-score 和排名辅助目标；主 Huber delta=2，排名权重 0.2，分支／路由权重 0.1／0.01，训练年龄半衰期 730 天。AdamW 0.0003，64 股票日训练、128 股票日评估，EMA 0.9999 与首轮 warmup，验证 IC 选模及统一动态早停。精确配置见 [model-config.json](model-config.json)。

## 存储、效率与复现

不重新落地一整套归一化 Parquet。构建缓存时按批读取已有预处理，以至多一个原始月份的价格索引对齐相同键，替换价格第二视图后直接写入 FP16 数组。原始价格文件的长度及 SHA256 必须匹配旧预处理的数据来源，额外指纹写入本版 `data-manifest.json`。输入不同是允许的研究变量，标签、股票池及评估器仍可与历史模型比较。

打包布局与父版相同，因此预计新增训练缓存约 **38.7 GiB**，双集评测缓存约 **9.85 GiB**，实际以构建记录为准。构建时多读取原始价格；索引内存按单月规模检查，切换月份释放，进入训练前关闭。缓存加载后的训练计算量与父版接近，不能以参数相同代替实际吞吐测量。父版八轮训练及验证约 118.77 分钟，仅作成本参照。

[训练缓存实现](../../common/geometry_resident.py)、[评测缓存实现](../../common/geometry_evaluation_cache.py)与[价格输入变换](../../common/price_geometry.py)为新系列共享模块。缓存身份包含输入契约、数据清单、精度、协议与实现指纹，不包含模型名称、网络宽度或学习率；后续相同输入的新模型可以复用。不同数据、划分或输入规则仍产生新键，不跳过来源检查。这些模块随 ready 候选冻结，改变输入语义时使用新实现和契约，不修改已在训版本的依赖。

控制器传入旧两种训练缓存格式时，本版只读其 manifest 并选择自己的缓存路径，不覆盖旧目录。尚未执行实际全量缓存构建，也没有删除旧缓存。

默认 [predict](v1601_predict.py) 与 [predict_fast](v1601_predict_fast.py) 均按股票日共享编码；原始价格在已经查询的 Bar 上直接转换，不新增平台行情查询。参考入口单独保存在 [predict_reference](v1601_predict_reference.py)，用于定向检查。平台导出应把 `common/price_geometry.py` 放在依赖它的模块之前载入；训练复现还需包含两个共享缓存模块。当前尚无正式权重或平台提交材料。

## 实现验证

- [核心检查](../../tests/test_v1601.py)：实际损失和缺失标签、八时点因果性、共享读出、原始／EMA／优化器／RNG 精确恢复、缓存与父版隔离及新模型共享。
- [输入检查](../../tests/test_v1601_inputs.py)：价格共同坐标、回退和缺失、数量与 z 不变、完整键对齐、原始来源篡改拒绝、与父版全部初始权重相同。
- [完整合成入口](../../tests/test_v1601_entrypoint.py)：预处理、月度／全局训练、目标覆盖、EMA 双集评测，缓存与原生输入逐值一致，旧缓存保留。
- [平台入口检查](../../tests/test_v1601_predict.py)：动态股票池下 fast／参考输出、整日／盘中部分请求一致，输出有限且键唯一，不读取标签或 exposure。

这些 CPU 合成检查不代表正式行情效果、GPU 默认批量通过或平台运行通过。CPU 默认规模预检通过；正式训练由另一 session 做 GPU 预检后串行执行一次。发布状态及源码指纹见 [experiment.json](experiment.json)。

[真实输入抽样](../../experiments/v1601-input-smoke.json)另核对了 2020 年 6 月首 4096 条预处理记录与原始价格的键对齐，z 及数量 c 逐值不变，没有生成新缓存或读取标签。该月价格索引的 Pandas 内存估计约 0.70 GiB；不是构建进程峰值，也不能外推所有月份。全部 20 项 CPU 测试通过，检查及源码清单见 [readiness](../../experiments/readiness/v1601.json)。
