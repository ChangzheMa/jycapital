# v2101：收益与未来数量状态共同学习

v210x 新系列首版，run 为 `v2101-quantity-state-s42`，父方案及设计时本地最优为 v1601。针对[双集 IC 0.25 目标](../../docs/ic-target-research-20261023.md)，检验未来成交与盘口数量监督能否帮助收益表示。采用 seed 42 从头训练，**不继承父权重**。2026-10-23 已发布 **ready**，[实现验证记录](../../experiments/readiness/v2101.json)及源码已冻结；正式训练和双集评测由调度 session 执行，当前尚无收益改善证据。

[研究依据](../../docs/temporal-liquidity-research-20261023.md)包含近期原始论文、v1901 的负结果、v1601 时间敏感度，以及 1,280 个训练股票日的数量目标诊断。它与 v2001 的输入归一化方向独立；保留 v1601 已有效的 75 通道、共同价格坐标和三频股票日编码，不叠加未完成评估的新输入方案。

## 结构与监督

模型共 **3,365,542** 个参数，相对 v1601 增加 **846,550** 个，约 33.6%。主干仍为三频日内／跨日 GRU，隐藏宽度 192、融合宽度 384。变化集中于共享表示之后的任务组织与监督：

| 部分 | 实现 |
| --- | --- |
| 共享与专属特征 | 四个共享 MLP 特征专家，以及收益、数量各一个专属专家；每个为 384→256→192 |
| 任务路由 | 收益与数量各自从四个共享专家和自身专属专家中混合，不混合另一任务的专属专家 |
| 数量输出 | 数量表示经 192→128→22 预测下一根 30 分钟 Bar 相对最后已知同频 Bar 的数量变化 |
| 收益读出 | 拼接收益表示、数量表示及预测数量变化，经 406→256→2 输出原收益／排名目标 |
| 主监督 | 已提供 `vwap_return` 的原截面 zscore／rank zscore；Huber delta=2／1，排名权重 0.2 |
| 辅助监督 | 既有训练标准化 `z` 通道的后续数量变化，Huber delta=2；成交量／额、十个盘口数量、十个委托数字段三个组等权 |
| 优化 | 主收益梯度保持，数量梯度移除冲突分量并限制范数；有效辅助系数最高 0.5 |

主收益标签、股票池、正式时间划分、验证 IC 选模和动态早停不变。没有重算或反推 `vwap_return`，没有读取 `exposure`、引入手工因子或外部模型权重。下一 Bar 数量变化是训练辅助目标，不能称为重建逐笔订单流。

若已有数量值为 \(q_t\)，提供的下一 Bar 数量值为 \(q_t^+\)，辅助目标为 \(q_t^+-q_t\)，模型从历史行情估计 \(\widehat{\Delta q}_t\)。绝对状态估计 \(q_t+\widehat{\Delta q}_t\) 与后续状态比较；推理的收益读出只接收网络估计的变化和数量表示，**从不接收未来数量真值**。

三个字段组分别按有限目标和日期权重计算均值，再在有监督的组间等权，避免二十个盘口字段仅因数量多而压过成交字段。原收益标签缺失和辅助数量缺失分别处理；辅助缺失不删除原有收益样本。训练股票日资格沿用父版的主标签规则，不额外引入池外样本。

## 时点、缺失与目标读取

辅助目标使用已提供 30 分钟数据的下一根 Bar：

| 预测时点 | 辅助目标 Bar 结束时刻 |
| --- | --- |
| 09:30 | 10:00 |
| 10:00 | 10:30 |
| 10:30 | 11:00 |
| 11:00 | 11:30 |
| 11:30 | 13:30 |
| 13:30 | 14:00 |
| 14:00 | 14:30 |
| 14:30 | 15:00 |

午休被显式跳过；这一辅助任务不是墙钟三十分钟收益。09:30 的最后已知同频数量取前一交易日最后 Bar。没有前日历史或已知数量缺失时，仅跳过对应辅助位置，主监督仍按原规则执行。

[训练目标读取器](v2101_quantity.py)只允许训练时间范围内的股票日，最迟目标结束时刻也须位于训练边界内。它从既有 30 分钟数组按 batch 取得当前交易日与前日八个槽位，恢复稀疏 FP32 溢出值；原生加载和全局 FP16 缓存路径遵守各自既有精度。当前股票池之外的时点不产生辅助监督。

收益／排名加未来数量、最后已知数量、前日同槽位基准，共 **68 个训练目标通道**；预测输入仍为 **75 通道**。目标读取器不在模型或平台预测模块的导入闭包中，行情窗口的未来槽位照常清零。训练时使用未来观测作为监督，不允许其通过标准化、目标掩码或参考基准进入早先预测。

## 主任务优先的梯度组合

方法参考 [PCGrad 的正式论文](https://proceedings.neurips.cc/paper_files/paper/2020/file/3fe78a8acf5fda99de95303940a2420c-Paper.pdf)中移除冲突梯度的思想。本版采用**非对称、收益优先**的全参数变体，不声称与原文随机任务顺序、双向投影算法完全相同。原论文实验主要为视觉和强化学习，不构成本项目 IC 提升证据。

令 \(g\) 为收益加排名主任务梯度，\(a\) 为数量任务梯度。当 \(g^\top a<0\) 且 \(\lVert g\rVert>0\) 时：

\[
a_{\perp}=a-\frac{g^\top a}{\lVert g\rVert^2}g.
\]

没有冲突时保留 \(a_{\perp}=a\)。随后限制辅助梯度范数：

\[
s=\min\left(1,\frac{\lVert g\rVert}{\lVert a_{\perp}\rVert}\right),\qquad
g_{\mathrm{combined}}=g+0.5s a_{\perp}.
\]

投影后辅助梯度为零时不增加辅助更新；主梯度为零时也不引入额外辅助方向。范数和内积以 FP64 累加，实际参数梯度保留 FP32，再统一裁剪并交给 AdamW。该规则约束的是当前 batch 的原始梯度关系，**不保证 AdamW 更新后主损失单调下降，也不保证正式 IC 提高**。

每个 batch 只进行一次共享前向，分别求两个任务梯度；这增加反向计算，换取较可控的任务干扰。日志中的主损失加 0.5 倍辅助损失仅为监控标量，不是投影后梯度必然对应的势函数。恢复继续保存模型、AdamW、EMA、随机状态、股票日游标及所有诊断累积量。

## 诊断与资源

数量状态按共同有效样本比较模型、最后 Bar、前日同槽位和标准化零基准，保留各字段组的 SSE／样本数及 MSE；无共同样本时标注未定义，不将占位零解释为完美效果。模型与最后 Bar 的误差比较也衡量是否学到了数量变化，而非仅复制水平。

同时记录两任务梯度余弦、冲突比例、范数与实际辅助缩放，任务路由熵，以及数量通路被置零时收益输出的变化。后者既记录原 RMS，也记录各预测时点在 batch 内去均值后的 RMS，减少单纯偏置差异的误导；这是训练批次作用诊断，不是正式截面 IC，也不证明数量通路带来有效 alpha。

[缓存身份核对](../../experiments/v2101-input-cache-compatibility.json)确认与 v1601 复用训练 `c760f388…58563b`、验证 `b51e456d…52d800c`、测试 `749e20cf…da5`。没有新增全量行情或全量辅助目标缓存；数据契约、源文件和目标组织另保存在正式运行的 `quantity-supervision.json`。不能将缓存复用描述为零磁盘运行成本，权重和评测产物仍需独立保存。

默认训练／推理为 **64／128 股票日**，主机预留 **2 GiB**，AdamW 学习率 0.0003、权重衰减 0.0001；时间权重和 EMA 0.9999 首轮预热沿用父版。默认宽度 CPU 预检为 2 个训练股票日、4 个推理股票日，三次优化步约 0.55／0.52／0.53 秒；它不是正式 GPU 吞吐或全量训练时间。完整默认批量由训练 session 在模型间隙确认。

[默认预测](v2101_predict.py)与 [fast 预测](v2101_predict_fast.py)保持相同，八时点共享历史编码；推理仍需计算数量表示与预测变化，不能声称整个辅助网络都可删除。尚未进行真实全区间平台计时，也未生成未评测候选的提交包。

正式完成后比较父版／当前最优 v1601 及能够精确绑定的平台最优，并报告双集 IC、Rank IC、稳定性、月份与时点、距 0.25 的差距和新增成本。辅助任务改善只用于解释机制；只有正式验证 IC 达到既有晋级标准、覆盖完整后才默认生成 fast 材料。
