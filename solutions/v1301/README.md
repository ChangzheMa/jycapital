# v1301：完整截面目标与分块重计算

v130x 完整截面目标与训练组织系列首版，直接基于已完成的 [v1002](../v1002/README.md#冻结结果与平台材料)，该版本也是设计时的本地最优参照。run 为 `v1301-complete-cross-section-s42`，seed 42，从头初始化，不读取父版训练后权重。正式训练由另一 session 串行执行，状态见 [experiment.json](experiment.json)。

## 研究依据与组合

v1002 已取得验证／测试 IC 0.091592／0.097627，但训练仍以随机股票日的点损失为主。本版把训练目标直接延伸到每个预测时点的完整股票截面，同时保留原 Huber 锚点及多分支监督。[文献核验](../../docs/cross-sectional-objective-research-20261022.md)记录了近期 CalibRank、MAPLE 及日期分组研究的原始来源、选模口径与局限。v4 的纯相关性训练未晋级且输出幅度失去校准，v7e 及后续点监督有正向证据，因此本版采用联合目标。

模型结构、75 通道输入、480／288／168 三频窗口、当天因果前缀和公共推理输出均与 v1002 同构，参数量仍为 **2,418,576**。完整默认网络在相同种子下的初始参数与父版完全一致；这是从头初始化检查，不是权重迁移。

| 部分 | 冻结设计 |
| --- | --- |
| 更新单位 | 每次使用一个训练交易日的全部合格股票日，分别计算八个时点的截面目标 |
| 内存控制 | 最多 1000 股票日输入，每 64 个为网络计算块；保留随机状态的非重入 activation checkpoint |
| 原点监督 | 收益 Huber delta=2、排名 Huber delta=1，排名／分支／路由权重 0.2／0.1／0.01 |
| 新截面项 | 权重 0.2 的负稳定化 Pearson 相关性；分母使用标准差尺度 0.02 的平滑项 |
| 时间权重 | 保留训练日历年龄函数；改为按全训练有效日期的平均权重归一化，单日整体乘权重 |
| EMA | 基础衰减 0.9999 对应 64 股票日；实际衰减按本次处理的股票日数取幂，首轮 warmup |
| 其余训练 | AdamW 0.0003、dropout 0.1、FP32 GRU 与支持时的 BF16 autocast；验证 IC 选择、统一动态早停 |
| 推理 | 128 股票日一批、fast 共享编码；输出混合收益头，无在线更新或截面损失计算 |

精确配置见 [model-config.json](model-config.json)。batch 组织、相关性目标、时间权重归一化和 EMA 单位构成整体改动；不能将后续效果全部归因于相关性项。

## 目标定义与尺度

对日期 \(d\) 的每个时点 \(c\)，只使用原规则下有效的标签。完整截面标准化收益为 \(z\)，预测为 \(p\)，中心化后的总体方差与协方差均用 Float64 计算。辅助相关性定义为

\[
\widetilde\rho_{dc}=\frac{\operatorname{Cov}(p,z)}{\sqrt{(\operatorname{Var}(p)+\epsilon^2)(\operatorname{Var}(z)+\epsilon^2)}},\qquad \epsilon=0.02.
\]

每个时点分别中心化，再在有效时点间等权平均；不把八个时点展平求一次相关性。原目标预处理已按协议剔除少标签或常数标签截面，本辅助函数另外防御合成输入中的退化情况。常数预测不会被丢弃，平滑分母使其仍有有限梯度。该量是正式 Pearson IC 的稳定化训练代理，不能将训练日志当作验证 IC。

设原日历年龄权重为 \(w_d=0.25+0.75\cdot2^{-\mathrm{age}_d/730}\)，\(\bar w\) 为全训练有效日期上的平均值，单日损失为

\[
L_d=\frac{w_d}{\bar w}\left(L_{\mathrm{main}}+0.2L_{\mathrm{rank}}+0.1L_{\mathrm{expert}}+0.01L_{\mathrm{router}}-0.2\operatorname{mean}_c\widetilde\rho_{dc}\right).
\]

点损失与分支代价仍按当日有效样本平均，近似平衡分配仍使用温度 0.25、12 次迭代，并停止梯度。时间权重放在日损失外部，避免同日权重在 batch 内相消。正式验证／测试的标签、覆盖及截面等权评价不变。

每次优化后，若本次包含 \(n_d\) 个有效股票日，EMA 衰减为 \(0.9999^{n_d/64}\)。这保留按数据量衡量的衰减尺度，但优化器更新次数、梯度和 EMA 轨迹均与父版不同。恢复记录包含日期游标、日期排列指纹、累计股票日数、原始／EMA 参数、优化器和 RNG。

训练历史保留原损失分项，新增 `train_correlation_loss`、`train_stabilized_correlation`、`train_prediction_std`、`train_day_weight`、有效相关截面数和 EMA 累计股票日数。损失分项包含日权重，相关性及预测标准差诊断不含日权重；逐轮日志按有效样本数汇总 batch 统计，不能冒充完整训练区间一次性计算的正式 IC。

## 完整截面与效率证据

[只读训练索引审计](../../experiments/v1301-calendar-feasibility.json)确认：970 个交易日、776 万原始样本、97 万股票日，每个股票日都有八个不同预测时点。沿用现有标签资格后，有 **967,872** 个合格股票日、**7,742,958** 个有效样本；每天合格股票数为 **990—1000**。本版每轮执行 **970** 次优化，每日最多 16 个网络计算块。审计读取索引和既有目标数组，没有读取价格窗口或改写缓存。

分块只限制网络中间激活；全部分数汇总后才计算完整目标，再反向重计算各块。因此不是分别优化小块相关性，也不是仅对部分股票采样。一次完整日的 FP32 输入张量上界约 280.8 MB，额外还有预取、掩码、梯度和优化器等内存；该估算不等于峰值显存。

与 v1002 相比，每轮更新次数从 15,123 减少到 970，激活重计算增加前向计算，收敛所需轮数可能增加。实际 GPU 资源和耗时由训练 session 的完整默认批量预检及正式运行确认，不承诺同速，也不为用满时间强行延长训练。[缓存身份核验](../../experiments/v1301-input-cache-compatibility.json)确认同一输入契约，正式运行仍核对自身数据指纹；旧缓存保持只读。

## 检查与交接

[CPU 检查](../../tests/test_v1301.py)覆盖完整日期成员保留、变长日期边界、时间权重不相消、逐时点相关性公式与数值梯度、常数预测梯度、全目标跨块汇总，以及带 dropout 的 FP32／CPU BF16 重计算输出、梯度和 RNG 精确一致。还检查了实际股票日数控制的 EMA、默认参数初始化、三频因果性、共享推理和中断后的精确恢复。

[完整入口检查](../../tests/test_v1301_entrypoint.py)使用三个训练日和变动股票数的合成 Parquet，走通全局 FP16 缓存、日期双缓冲、训练、EMA 选模及验证／测试；核验了 119 个有效训练标签均被保留、三次日期更新及留出输出。CPU 默认规模预检仅使用小合成批量，不能代替整日 1000 股票的 GPU 预检。证据与代码指纹见 [readiness](../../experiments/readiness/v1301.json)。

一次正式运行，按验证 IC 选模，测试只在冻结后评价。若达到改善条件，再从冻结源码和权重生成 fast 平台材料；现有输入和推理同构不等于已验证平台运行或训练收益。
