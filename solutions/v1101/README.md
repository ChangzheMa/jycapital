# v1101：原始字段结构编码与适度扩容

v110x 字段结构编码系列首版，以已完成的 [v901](../v901/README.md#冻结结果与平台材料)为父版本和本地验证最优参照。run 为 `v1101-structured-fields-s42`，seed 42，从头初始化；正式训练由训练 session 串行执行。本版当前只有实现检查，没有正式成绩或平台材料。

## 研究依据与组合

[最新文献核验](../../docs/structured-input-research-20261022.md)区分了字段结构、原始数据范围、归一化、标签与评估条件。已有论文的高频分类、重建和人工特征增强结果不能直接当作分钟截面收益 IC 的证据。本地 v901 支持继续保留当天多频输入和股票日共享；v801／v802 的当前集合头未改善，故本版在单股票内部学习字段交互。

每频原有输入为 72 个数值通道与 3 个标志，线性投影可以学习任意组合。本版在保留该投影的同时增加结构分支，让网络利用字段定义中的五个盘口档位及不同字段组；主干宽度 160→192。结构分支和扩容一起评价，不能单独归因。

| 部分 | 冻结设计 |
| --- | --- |
| 原始输入、窗口与缓存数值 | 与 v901 相同，75 通道，1／5／30 分钟均包含当天已经结束的前缀；480／288／168 槽位 |
| 盘口分支 | 每档重排已有 z／c 的买卖价格、数量、订单数，共 12 个数值，再加盘口完整与 Bar 可用标志，14→24 维共享投影 |
| 档位交互 | 保留 5 个位置；共享通道的 5→16→5 MLP 学习档位关系，24→48→24 MLP 学习通道关系，各有可学习残差尺度，初值 0.1 |
| 非盘口分支 | 原 6 个字段的 z／c 及其组完整、Bar 可用标志，14→32 维投影 |
| 残差合并 | 结构分支拼接所有档位、非盘口表示及原 3 标志，投影到 192 维；初始尺度 0.1 加到原 75→192 线性投影上 |
| 时序与跨频 | v901 的日内／跨日单向 GRU，隐藏维度 192；两个同一时点的跨频交互块，融合宽度 384 |
| 参数量 | **2,296,710**，全部可训练 |
| 监督与选择 | 原收益 zscore Huber delta=2，加权重 0.2 的独立排名头；EMA decay=0.9999、首轮 warmup，验证 IC 选模、统一动态早停 |
| 优化与批量 | AdamW 学习率 0.0003，dropout 0.1；每步 64 股票日、最多 512 个目标；评估每批 128 股票日 |

完整参数见 [model-config.json](model-config.json)。所有数值字段在结构分支中各出现一次，原线性路径同时保留完整输入。盘口组不完整只通过标志表达，不能据此把仍有效的原字段清零。档位轴表达字段身份，不强制逐字段标准化后的价格仍满足单调关系。

## 因果性、效率与缓存

结构分支仅处理同一 Bar 的字段，不跨时间、股票或预测时点。之后沿用 v901 的单向日内前缀和跨日历史状态共享；八个预测时点复用同一股票日计算。训练时新增 dropout 也在共享路径中复用，这是组合方案的一部分；eval 时共享路径与逐样本参考一致。

不构造价差、比例、盘口汇总、人工技术指标或新标签，也不改变归一化。额外计算发生在低维档位表示上，避免为各字段组分别运行完整时序主干。参数量与 CPU 检查不能替代 GPU 吞吐；实际时间和显存由训练 session 预检及正式运行记录，不承诺比 v901 更快。

训练 resident 构建模块与 v901 **逐字节一致**，数据契约、协议和目标变换相同。[只读兼容性核验](../../experiments/v1101-input-cache-compatibility.json)使用 v901 已冻结的数据清单计算出同一缓存键，未打开行情数组或修改缓存。正式运行仍检查自己的数据清单；满足相同身份时可复用已有缓存，不能绕过指纹强制使用。若调度器传入旧三频历史格式，仍按既有入口只读兼容并转到正确的新格式目录。

评估缓存模块使用本版本名称，身份可能不同，由自己的检查选择或构建；不得冒充 v901 的评估缓存。评估逐段加载，保持原 8 GiB 内存预留。训练源码和配置不修改已运行的 v1001 或父 v901。

## 实现检查与交接

[模型检查](../../tests/test_v1101.py)验证字段映射完整、结构分支不跨 Bar、盘口不完整时有效字段仍有梯度、关闭结构残差后精确回到原投影、共享／逐样本预测及三频逐时点因果性、原始目标资格、精确恢复与训练缓存身份一致。[完整入口检查](../../tests/test_v1101_entrypoint.py)运行合成 Parquet 的预处理、月度与全局股票日训练、缓存恢复和完整双集推理；确认当天粗频输入存在、旧缓存保持原样、输出覆盖及参考对照一致。

CPU 默认规模预检确认所有参数梯度和输出有限。唯一候选及实际发布状态见 [experiment.json](experiment.json)；通过实现检查不代表本地模型改善。未来只有正式验证 IC 晋级且覆盖完整，才从冻结权重生成默认 fast 平台材料，按既定简化约定检查转换。
