## 共享 fast 平台材料

两个参数文件逐字节复用原组件附件，每个均小于 50 MB。平台共享一次行情读取、归一化和切窗，两个网络分别按股票日共享历史与当天因果前缀；全部股票计算完成后才做截面组合，不能在小批量内单独标准化。不读取标签或离线预测，推理不更新权重。

实际 JSON 权重与组合 checkpoint 逐张量完全一致。隔离三文件的 37 行合成窗口与逐样本参考最大差约 1.02×10⁻⁶；完整合成 `main` 与两个组件分别运行后组合的最大差约 6.51×10⁻⁶，对应原始组件分数最大差为 5.96×10⁻⁸／2.98×10⁻⁸，小截面标准化放大了 Float32 差异。该合成例中行情查询从分别运行的 15＋15 次变为共享的 15 次，未测量时间加速倍数。

[核验清单](../../experiments/v1401-frozen-equal-ensemble-s42-fast-submission.json)还包含导入不查询行情、训练复现保护、输出类型／键、独立恢复两套训练源码的检查。未重跑长行情或速度基准，未验证平台运行。[专用检查记录](../../experiments/readiness/v1401.json)与[三个聚合测试](../../tests/test_v1401.py)保留了实际范围。
