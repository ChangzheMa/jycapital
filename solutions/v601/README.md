# v601：日内因果卷积与跨日 GRU

[文档目录](../../docs/README.md) · [持续研究](../../docs/continuous-research.md) · [候选清单](experiment.json) · [父版本 v303](../v303/README.md)

v60x 开启日内卷积与跨日递推结合的结构系列。v302／v305 的时间压缩没有超过原分辨率的 v303；v601 保留全部时间槽位，通过日内并行卷积检验另一种效率路径。以 v303 为父版本，从头初始化，监督目标、Huber delta=2、训练和评估协议保持一致。

## 结构与因果性

三路 75 通道输入先投影为 96 维，再按交易日分组：

| 部分 | 实现 |
| --- | --- |
| 1 分钟日内编码 | 4 个残差块，膨胀率 1／2／4／8 |
| 5 分钟日内编码 | 4 个残差块，膨胀率 1／2／4／8 |
| 30 分钟日内编码 | 2 个残差块，膨胀率 1／2 |
| 每个残差块 | 两个 kernel=3 的因果 Conv1d，各接 GELU 和 Dropout=0.1，残差相加 |
| 每日读出 | 最后可见状态与可见位置均值拼接，Linear 192→96、GELU |
| 跨日编码 | 原有 96 维单向 GRU，FP32 递推，读取最后可见交易日 |
| 融合输出 | 三路状态加八维预测时钟，原有 256 维预测头 |

卷积仅左侧补零，不跨日卷积，不加入 LayerNorm。日内卷积的局部感受野分别为 61／61／13 根 Bar；每日均值读出聚合当日全部可见位置，因此每日表示仍可依赖完整可见日内历史。历史缺失槽位保留输入标志，不能将缺失槽位从时间轴删除。今日未来槽位在输入处清零，同时每日最后状态和均值均只使用截点前位置；09:30 直接读取昨日的跨日状态。

模型保留 `hierarchical_gru` 家族接口和 `MultiFrequencyGRU` 类名，配置用 `intraday_encoder=causal_residual_tcn` 明确日内替换。这样可继续使用已有评估、导出命名与 GPU 预检接口；不能据类名将该版描述成两级 GRU。

## 成本与实验边界

共 **876,257** 个参数，约为 v303 的 2.02 倍，低于百万规模。没有缩短输入时间轴；日内卷积增加并行算术量及中间激活，可能更快，也可能受到显存带宽和计算量限制。速度与显存以训练 session 的默认批量预检及正式结果为准，不预先宣称加速。

这版同时改变日内编码和每日读出，结果只用于评价整体结构，不能分别归因。输入、缓存、种子 42、全局随机 batch 512、原收益标准化目标、Huber delta=2、优化器及验证 IC 早停与 v303 相同。

## 执行与验证

唯一正式运行为 `v601-causal-tcn-gru-s42`，由训练 session 在 ready 后串行执行：

```powershell
.venv-training/Scripts/python.exe -u solutions/v601/v601_train.py --training-run outputs/preprocessing/v2-20261010 --holdout-run outputs/preprocessing/v2-holdout-20261011 --run-dir outputs/runs/v601-causal-tcn-gru-s42 --evaluation-cache-mode stream --training-confirmed
```

CPU 检查覆盖卷积前缀不依赖后缀、未来梯度为零、八时点输出隔离、全部参数有限梯度、批量拆分、缺失历史、文本权重往返和确定性断点恢复；完整合成入口覆盖月度及全局两种模式。GPU 预检与正式训练由训练 session 完成。

## 冻结结果

2026-10-21（UTC+08:00）完成 8 轮训练，第 4 轮的验证 IC 最优；训练及逐轮验证合计 9,443.843 秒，约 2.62 小时。[比较摘要](../../experiments/v601-gru.json)保留当前本地验证最优 v501 与父 v303 两个参照。本版未晋级，不新增平台材料。

| 指标 | v303 验证 | v501 验证 | v601 验证 | v303 测试 | v501 测试 | v601 测试 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| IC | 0.085625 | 0.087199 | 0.076855 | 0.090160 | 0.090330 | 0.083834 |
| Rank IC | 0.083970 | 0.084019 | 0.076309 | 0.084293 | 0.085085 | 0.080749 |
| IC IR | 0.785680 | 0.803122 | 0.738534 | 0.763490 | 0.771749 | 0.728722 |
| Rank IC IR | 0.881964 | 0.899665 | 0.826170 | 0.808206 | 0.838800 | 0.773836 |

相对 v501，验证／测试 IC 下降 0.010345／0.006497；相对父 v303，下降 0.008771／0.006326。对两个参照，验证各 6 个月的 IC、Rank IC 均未改善；测试各仅 1/6 月改善。双集覆盖率和最低截面覆盖均为 100%，未定义 IC／Rank IC 截面均为零。

总训练时间较短主要因为较早停止。v601 每轮含验证平均约 1,180 秒，v303 约 949 秒；本次组合没有观察到单轮效率优势，不能把 8 轮对 12 轮的总时间差当成网络加速。该对比包含数据和系统开销，并非独立内核基准。

[信号诊断](../../experiments/v601-signal-diagnostics.json)的验证／测试换手代理为 0.666508／0.664583，高于 v501 和 v303。MSE／MAE 虽更小，输出未经收益校准，不能据此替代 IC／Rank IC 的结论。本版同时改变卷积编码和每日读出，不能据其负结果推断所有卷积结构无效；当前不把这一组合加入 v701，也不继续密集扫描膨胀率。平台更新由用户同步，未主动查询平台分。
