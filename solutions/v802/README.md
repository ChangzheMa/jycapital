# v802：完整截面的时序与关系联合适应

属于 v80x 股票集合交互系列，以 [v801](../v801/README.md) 为结构父版本，run 为 `v802-joint-market-gru-s42`。从 v801 中取出未改变的本地 GRU 主干，其初值逐张量等于 v501 EMA；集合残差模块重新初始化为零输出，不继承 v801 已训练的残差。当前只有 CPU 合成实现检查，正式训练由训练 session 串行调度。

## 研究依据与组合改动

v801 把新增尝试缩短到约 16 分钟，但验证／测试 IC 及 Rank IC 均低于 v501，验证 IC 在首轮后持续下降。它的 IR 和换手代理有所改善，因此不能简单判定集合交互完全无效；同样不能据此断言冻结主干是失败原因。近期论文及适用性审查见[研究方向](../../docs/research-directions-20261021.md)，没有将日频指数、外部文本或波动率任务的结果当作本项目收益 IC 证明。

本版的整体假设是：允许关系信号反向调整时序表示，并限制对已有表示的偏移，可能比冻结表示上单独扩大头部有效。一次合并以下改动，结果只用于评价整体方案：

| 部分 | v801 | v802 |
| --- | --- | --- |
| 时序主干及原预测头 | 冻结、始终 eval | 全部参与训练，训练时恢复原 dropout |
| 主干学习率 | 不更新 | 0.00003 |
| 集合模块学习率 | 0.0001 | 0.0001 |
| 集合模块 dropout | 0.1 | 0.2 |
| IC 辅助损失权重 | 0.05 | 0.01 |
| 训练表示 | 一次 FP32 编码后缓存 | 每步从原始预处理窗口重新计算，梯度回传到 GRU |
| 内存组织 | 冻结表示按截面读取 | 同一完整截面的股票分为最多 128 只的编码块，保存输入并按需重算激活 |

网络形状不变，总参数 **2,129,158**，本版全部可训练。原收益 zscore Huber delta=2、原始输入频率和时间分辨率、完整截面采样、EMA decay=0.9998／首轮 warmup、验证 IC 选模、动态早停及种子 42 保持固定。

完整截面内的有效目标为 \(z\)，本版损失为：

\[
L = \operatorname{Huber}_{\delta=2}(\hat y,z)+0.01\left(1-\operatorname{Pearson}(\hat y,z)\right).
\]

标签无效只影响损失，不删除上下文股票。股票池不按未来标签筛选，原始目标仍在完整截面标准化。`batch_size=1000` 是 GPU 预检参考股票数，加载器按各时点实际股票数组织完整截面，不能据此截断或拆成不同的市场上下文。

## 编码重算与推理

训练分块只作用于每只股票独立的时序编码，收齐所有股票表示后才执行两层集合交互；损失计算一次，梯度通过所有编码块返回原窗口和主干。激活重算使用 PyTorch 2.11 的非重入实现，并保留 dropout 随机状态；选择依据见[官方说明](https://docs.pytorch.org/docs/2.11/checkpoint.html)。这以额外计算换取较低激活内存，不宣称一定加速。

本版不使用 v801 的冻结表示缓存，因为主干每步改变。复用的是原 FP16 行情缓存及其 FP32 溢出恢复语义。验证／测试每轮重新提取当前权重的表示，按股票日复用单向前缀，再按完整 `(date, clock)` 截面预测；评估分块顺序执行，避免同时预取两个行情块的额外主机内存。8 GiB 内存保护保持原配置。

平台默认沿用相同 fast 逻辑：先分批编码股票日，再收齐完整时点做集合交互。没有跨时点注意力，未来 Bar 仍不能影响早时点输出；股票顺序和编码批量不定义市场上下文。按用户的简化约定，以逻辑审查、已有输入／前缀证据及必要的合成对照验收，不逐版重复长区间平台测速。

## 复现、检查与调度

初始化检查 v801 最佳 EMA 文件及其主干张量指纹。新 checkpoint 同时保存**原始初始化主干**与训练后的完整模型，二者不混用；若未来导出，文本材料须保留 `initialization_state_dict`，使独立训练复现可以恢复真正的初值。推理只使用最终完整模型，无需读取父模型文件。

两个 AdamW 参数组分别记录主干和集合模块的学习率。恢复保留原始权重、EMA、优化器、随机状态、完整截面游标和最初主干副本。测试集仍只评估按验证 IC 选定的 checkpoint。

[模型检查](../../tests/test_v802.py)覆盖全部参数可训练、初始化起点、跨股票梯度与未来隔离、重算／不重算的 dropout 随机状态、梯度和更新逐值一致。[完整入口检查](../../tests/test_v802_entrypoint.py)使用股票数变化的合成截面，走通预处理、行情缓存、联合训练、断点恢复及 fast 双集评估；与独立逐样本时序编码、完整截面预测对齐，恢复后的权重、EMA、AdamW、历史指标和随机状态一致。

这些检查不代表正式行情收益或 GPU 吞吐。默认完整截面的 GPU 预检由训练 session 在模型间隙执行；该版比 v801 需要更多时序计算，实际耗时和资源以正式记录为准。唯一候选登记见 [experiment.json](experiment.json)。v701 原 run 的资源恢复仍由训练 session 控制，本版没有修改它的研究源码。
