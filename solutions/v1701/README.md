# v1701：长期历史状态条件化短期信号

v170x 长期状态系列首版，直接父版为已完成的 [v1102](../v1102/README.md#冻结结果)，run 为 `v1701-long-history-s42`。从 seed 42 重新初始化，设计时总体最优为 v1401；平台成绩尚无精确权重绑定。本版正式效果仍待训练 session 的一次训练及双集评测。

## 提分假设

已有模型最长回看约 20 个交易日，可能缺少解释短期价量形态的慢状态。本版保留短期三频通路，由当前表示读取过去 252 个已完成交易日的历史，再以残差参与收益排序。[文献与容量分析](../../docs/long-context-research-20261022.md)同时记录了短回看更优的反面证据，因此不预设长历史必然有效，也不在结果出来后连续搜索相邻窗口。

v1601 独立检验价格坐标，本版短期输入保持 v1102 的冻结 z/c。已有 `vwap_return` 直接作为监督来源，只做原标准化与排名加工，不重算收益公式，不使用 exposure 或外部预训练权重。

## 冻结设计

| 部分 | 设计 |
| --- | --- |
| 短期通路 | v1102 三频字段结构编码、两级 GRU、跨频交互、专家／路由；窗口仍为 480／288／168 |
| 长期输入 | 之前 252 个完整交易日，每天八根 30 分钟 z/c 序列及有效性标志，不含预测当天 |
| 日级编码 | 每天 8×75 个输入投影到 96 维；不计算人工日级因子 |
| 历史压缩 | 每四日形成一个 token，共 63 个；两层四头注意力，前置 LayerNorm、FF 倍率 2、dropout 0.1 |
| 条件读出 | 当前 384 维短期表示作为查询，共享历史键和值，读取对应状态；八个日内时点共用一次历史编码 |
| 残差 | 输出投影权重和偏置初始为零，残差尺度初始 0.1；没有有效历史时显式返回零残差 |
| 参数 | **2,863,057**，全部可训练；比父版增加 **344,065** |
| 训练 | 64 股票日一批、AdamW 0.0003；原 Huber／排名／分支／路由目标、时间权重及 EMA 保持不变 |
| 选模 | 验证 IC、统一动态早停；每版一次正式训练，测试不选择 checkpoint |

全部原短期参数的同种子初值与父结构逐值相同，零残差时初始预测也相同。该初始化是可控起点，不是改善保证；增加分支会改变训练中的随机数消耗，不能声称训练轨迹与父版相同。

缺历史保留左侧空槽位。按股票池日历估算，只有 74.02% 的训练股票日具有完整 252 日前置历史，实际行情缺失仍需掩码。模型不删除其余样本；无历史退回短期输出，部分历史按有效日／块掩码处理。

## 缓存与运行成本

[缓存身份核对](../../experiments/v1701-input-cache-compatibility.json)确认短期训练缓存仍为 `dbcd47ff…`，短期验证／测试仍为父 v1102 的 `02d6be41…`／`00d1181d…`。目录内的 `v1102_resident.py`、`v1102_evaluation_cache.py` 是原样保留的输入兼容模块，不包含父模型训练权重；其原始字节、协议、数据配置及加载语义共同支持原缓存身份。正式运行仍独立校验数据来源。

[长期旁路](../../common/long_history.py)单独按划分保存去重的 FP32 源值，以只读 mmap 取窗。模型输入仍采用与短期相同的 FP16 舍入及 FP32 极值保留，未将缓存存储精度冒充另一种模型输入精度。预测日当天严格排除，验证／测试允许使用此前已发生的训练期历史，不读历史标签作为输入。

预计新增数值容量：训练 **2.484 GiB**、验证 **0.845 GiB**、测试 **0.862 GiB**，合计 **4.192 GiB**，另计少量映射和元数据。现有短期评测缓存如果被清理，需要按原身份重建约 9.85 GiB；短期训练缓存继续复用，不再复制整套三频数组。

64 股票日的长期 FP32 输入缓冲约 36.91 MiB，另有量化、预取、搬运和网络激活开销。后台准备下一批历史，与短期预取和模型更新重叠。父版八轮训练及逐轮验证约 118.77 分钟，只作成本参照；本版完整 GPU 吞吐和总训练时间尚未测量。

## 平台 fast 与复现

[默认入口](v1701_predict.py)及 [fast 入口](v1701_predict_fast.py)均共享股票日编码。只扩展 30 分钟历史，1／5 分钟查询长度保持不变。30 分钟按月取数、按当前日期顺序归一化；历史按日保存，最多保留 253 日，不反复拼接全年网格。提前取到的后续日期不会交给当前日归一化或模型。完整截面归一化仍在筛取请求股票网格之前执行。

[参考入口](v1701_predict_reference.py)只用于本地核对。合成数据中使用非零长期输出，核验了 fast／参考、跨日拆分、盘中部分请求一致，以及 20 日窗口之外的历史确实能够影响输出。覆盖 26 个交易日、两个自然月时，fast 的 30 分钟原始取数不超过两次；这不是完整平台运行测速。

未来平台包需包含 `common/artifacts.py`、`common/long_history.py` 及 `v1701_long_model.py`、`v1701_platform_history.py` 等实际依赖；训练复现还需保留两份输入兼容模块。当前没有正式权重或提交材料。

这些检查证明实现行为，不证明评分提高。默认网络规模 CPU 预检通过；GPU 默认批量预检及正式双集评测由训练 session 执行，发布状态见 [experiment.json](experiment.json)。已有候选积压达到阈值后不再开启新模型，等待队列满足恢复条件。
