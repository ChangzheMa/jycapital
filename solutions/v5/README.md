# v5 四频 TCN 隐藏通道扩至 160

[文档目录](../../docs/README.md) · [父版本 v4](../v4/README.md) · [模型配置](model-config.json) · [冻结结果](../../experiments/v5-tcn.json)

运行 `v5-20261015-s42`，父运行 `v4-20261014-s42`，seed=42，选中第 6 轮权重。

## 相对 v4 的变化

仅将四个频率分支的 `hidden_dim` 从 128 扩至 160，参数量由 1,591,553 增至 **2,429,505**，增加 52.6%。融合层宽度保持 256，输入、归一化、残差结构、Dropout、纯 IC 目标及训练设置沿用 v4。权重从头初始化。

## 结果与局限

相对父版本，验证／测试 IC 增加 **0.000993089／0.000023146**，Rank IC 增加 **0.000531886／0.000588169**。测试 IC 基本持平，测试 IC_IR 从 0.685516 降至 0.665970；MSE／MAE 也升高，不能视为全面改善。

相对训练前本地最优 v1，验证 IC 仅高 **0.0000177135**，测试 IC 低 **0.010125403**。按验证 IC、覆盖与未定义截面规则属于本地改善候选，但优势很小，仅有单种子证据。

验证／测试覆盖均为 100%，无未定义相关系数截面。完整指标、逐月差值及资源开销见冻结结果，跨版本汇总见 [模型结果表](../../docs/README.md#冻结模型结果)。
