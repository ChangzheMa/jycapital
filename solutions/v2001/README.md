# v2001：共同数量坐标与因果可学习归一化

v200x 新系列首版，run 为 `v2001-causal-normalization-s42`，直接父版及设计时本地最优为 v1601。研究依据见[数量、价格路径审计及文献核验](../../docs/causal-normalization-research-20261023.md)。本版从 seed 42 重新初始化，检验输入表达与可学习归一化的整体变化，正式收益效果尚待一次完整训练和双集评估。

## 模型与输入

保留 v1601 的三频股票日共享骨干、四专家预测、Huber／排名辅助／分配目标、时间权重和 EMA。新的组合检验包含以下部分：

| 部分 | 定义 |
| --- | --- |
| 历史偏离视图 | 保留原有 36 个 z 数值 |
| 第二价格视图 | 保留 v1601 的 14 个同一已闭合 Bar 共同价格坐标 |
| 第二数量视图 | 十个委托量、十个委托笔数分别用训练期全局合并矩的共同中心和尺度归一化；保留全部原始字段，成交量和金额的 c 视图保持 |
| 价格参考 | 原价格几何使用的已闭合 Bar 价格中心取对数，保留 FP32，按训练期全局 close 对数统计标准化；通常为当前 Bar 的 close，缺失时沿用原价格几何的确定回退顺序 |
| 可用性 | 保留三个组标志，另加 36 个逐字段标志，表示该字段至少一个规范化视图可用；有效零数量不当作缺失 |
| 因果归一化 | 每个频率增加 32 维单向 GRU，在各交易日内按已知前缀产生价格、委托量和笔数三组的共同中心与正尺度 |
| 输入直连 | 原始输入投影直接读取新表示；字段结构分支读取可学习归一化结果，避免只能依赖被重新缩放的表示 |

输入总计 **112 通道**：72 个两视图数值、3 个组标志、36 个字段标志、1 个 FP32 价格参考。共有 **2,584,290** 个可训练参数，比 v1601 增加 **65,298** 个。

每组归一化使用同一时刻、同一股票的共同中心与正尺度：

\[
\widetilde x_{t,j}=\frac{x_{t,j}-\mu_{t,g}}{s_{t,g}},\qquad
s_{t,g}=0.1+\operatorname{softplus}(a_{t,g}).
\]

其中 \(j\) 属于组 \(g\)，\(\mu_{t,g}\) 与 \(a_{t,g}\) 来自该交易日截至 \(t\) 的单向状态。头部零权重与尺度偏置使初始中心为 0、尺度为 1。组内的正尺度变换保留可用字段的大小关系；缺失字段继续显式置零并保留标志。原输入直连仍保留未经过该自适应层的坐标。

该设计改变第二数量视图的参考系，不能假设保留了原 c 的全部作用。神经归一化不使用整个当前日的未来统计，八时点读出继续满足各自截点。价格参考只是原始输入的规范化参考，不生成或替换收益标签；`vwap_return` 继续直接使用已提供字段，只做原有标准化／排名加工。全过程不使用 exposure。

## 数据组织与效率

[缓存兼容性及容量](../../experiments/v2001-input-cache-compatibility.json)核对基础缓存仍为 v1601 的 `c760f388…`、`b51e456d…`、`749e20cf…`。本目录原样保留 `v1601_data.py` 和 `v1601_schema.py` 作为基础输入兼容依赖；它们不包含父版模型权重。

新公共实现为 [coordinate_inputs.py](../../common/coordinate_inputs.py)、[coordinate_resident.py](../../common/coordinate_resident.py) 和 [coordinate_evaluation_cache.py](../../common/coordinate_evaluation_cache.py)。旁路只保存 20 个 FP16 数量坐标、一个 FP32 对数价格中心和稀疏溢出记录。基础字段、标签和映射仍来自原缓存，旧目录保持只读；同一输入契约不按网络名称复制缓存。

训练加载器边校验边读取基础文件，只把前 52 个通道放入常驻数组，再加载新旁路，避免同时驻留完整父数组和全部新增数据。训练数组按真实形状预计约 **39.83 GiB**，三套旁路数值与指针预计新增约 **14.81 GiB**，均尚未实测正式数据构建；这些数值不含新的溢出记录、缓冲、框架或进程峰值。没有新增整套归一化 Parquet，也没有删除旧缓存。

评估模式仍支持 `auto / resident / stream`：resident 使用紧凑数组，stream 通过只读映射按请求取窗。缓存文件和参数的身份均须对应；重复网格位置、数据损坏或参数变化会被拒绝。缓存构建只读取授权行情和基础位置映射，标签值由原训练／评估链路保留。

正式配置为训练 64、推理 128 股票日，两个预取缓冲，主机预留 **2 GiB**。归一化 GRU、原行情编码和八个时点均按股票日共享；它增加小型前缀计算，不增加一整套八次独立切窗编码。具体 GPU 吞吐与峰值由训练 session 的默认批量检查和正式运行记录确认。

## 平台 fast 与复现

[默认入口](v2001_predict.py)和 [fast 入口](v2001_predict_fast.py)相同。从原有行情查询已经取得的原始字段计算数量坐标和价格参考，没有新增行情表或远程查询阶段；训练期统计来自随模型冻结的归一化参数。日内部分请求、动态股票池及无自身统计股票沿用因果历史处理。

[参考入口](v2001_predict_reference.py)独立按样本推理。[复现入口](v2001_reproduce.py)可从文本包恢复预处理及训练源码，并在显式确认后从授权原始数据重建所需基础缓存与旁路。平台运行需要三个新公共模块，以及本目录的基础输入兼容模块和实际模型依赖；导出时不能仅按旧 v1601 的源码清单收集。

当前仅有方案和实现检查，没有正式权重、平台提交包或完整平台测速。改善候选才从冻结运行导出 fast 材料。

## 验证与判定

[实现记录](../../experiments/readiness/v2001.json)包含 CPU 合成检查及实际源码指纹。检查覆盖[核心因果性、归一化和恢复](../../tests/test_v2001.py)、[无标签旁路构建与两种缓存读取](../../tests/test_v2001_cache.py)、[月度／常驻完整入口](../../tests/test_v2001_entrypoint.py)、[平台 fast 与参考路径](../../tests/test_v2001_predict.py)。

关键证据包括：非零归一化参数下八个时点的未来梯度为零；共同正尺度保持同组字段关系；有效零值、缺失和 FP32 溢出按同一规则处理；紧凑与映射读取逐值匹配原生输入；父缓存不被改写；预取不改变样本顺序或随机状态；原权重、EMA、优化器和随机状态精确恢复。平台合成检查包含动态股票池及缺少自身统计的股票，完整请求和部分请求与独立参考一致。

这些检查不证明 IC 改善。正式完成后比较父版、当时本地最优及可绑定的平台最优，并报告双集距 **0.25** 的差距、分时点／月份表现、稳定性及成本。多项变化只作整体方案评价，不将结果归因于单个坐标或归一化模块。
