# v2201：跨日同阶段的双轴历史编码

v220x 新系列首版，run 为 `v2201-phase-aligned-s42`，直接父版和设计时本地最优均为 v1601。目标是改善已有多日行情的表示方式，服务于[双集 IC 0.25](../../docs/ic-target-research-20261023.md)。采用 seed 42 从头初始化，不继承父权重。2026-10-23 已发布 **ready**，[9 项实现检查及默认宽度 CPU 预检](../../experiments/readiness/v2201.json)通过，正式收益效果待训练 session 完成一次训练和双集评估。

[研究依据](../../docs/phase-aligned-history-research-20261023.md)结合 Paloma、TimesNet、CycleNet 的机制与质量边界，以及本地数量状态和历史敏感度证据。这里的交易阶段由原日历与 Bar 槽位决定，没有估计或假定官方收益存在稳定周期。

## 输入与计算组织

原输入保持 75 通道、1／5／30 分钟 480／288／168 根 Bar，沿用 v1601 的共同价格坐标、数量视图及缺失标志。输入、股票池、提供的 `vwap_return` 和评估划分不变，不使用 `exposure` 或外部权重。

| 部分 | 实现 |
| --- | --- |
| 字段投影 | 父版原始残差与盘口档位结构编码 |
| 阶段信息 | 每频率一个共享的日内槽位嵌入，长度 240／48／8，初始全零；在逐 Bar 非线性编码前加入 |
| 1 分钟分支 | 保留先日内、后日末摘要跨日的顺序，同时使用新阶段嵌入和宽度 |
| 5／30 分钟分支 | 先对每个相同槽位沿交易日单向编码，再沿前日完整序列与当天前缀进行日内单向编码 |
| 历史与当前连接 | 前日完整日内状态直接传到当天第一根 Bar，09:30 读取前日末状态 |
| 容量 | 隐藏宽度 192→256，融合宽度 384→512，专家宽度 128→192，路由宽度 64→96 |
| 预测头 | 保留四个收益／排名专家及行情路由，八时点共享网络参数 |

共 **4,528,944** 个可训练参数，比 v1601 增加 **2,009,952** 个，约 **79.8%**。其中新增阶段嵌入为 75,776 个，其余增加主要来自宽度。组织方式、嵌入和容量一起变化，只评价整体组合，不能单独归因。

5／30 分钟路径如下，日期轴与阶段轴的参数均共享：

```mermaid
flowchart LR
    A[交易日 × 日内槽位 × 原字段] --> B[字段投影与槽位嵌入]
    B --> C[相同槽位沿交易日单向 GRU]
    C --> D[前日完整序列接当天前缀]
    D --> E[日内单向 GRU]
    E --> F[按八个截止位置读取状态]
    F --> G[三频融合与收益预测]
```

设投影为 \(h_{d,p}\)，其中 \(d\) 为交易日，\(p\) 为日内槽位。第一阶段在每个 \(p\) 上独立递推：

\[
u_{d,p}=\operatorname{GRU}_{\mathrm{day}}(h_{d,p},u_{d-1,p}).
\]

随后连接前一交易日完整的 \(u\) 序列与当前日的 \(u\) 序列，沿日内顺序进行第二次单向递推。预测只读取截止位置。这样，历史中相同时段的变化在日末压缩前已经可见，同时仍保留前日收盘附近的信息向当天前缀传递。

原窗口没有延长，也没有新增八套独立预测网络。纯时点常数不改变截面 IC；本版阶段嵌入参与各股票内容的非线性编码，其作用必须由正式结果检验。

## 因果边界与 fast

两个时间轴都单向。当前日某个未来槽位只能改变该槽位的当前日跨日状态，不能改变过去日状态或其他阶段的状态；随后的日内 GRU 也不能把该未来状态传到更早读出。过去交易日的完整数据在今天已经可知，可以参与早间预测。

09:30 没有当天常规 Bar，直接读取前日末状态；午休沿用原交易槽位日历，不添加虚构 Bar。缺失历史仍保留槽位及原标志，不因历史不完整删除样本。阶段嵌入表达已知日历位置，不把缺失 Bar 声称为真实观测。

[默认入口](v2201_predict.py)与 [fast 入口](v2201_predict_fast.py)相同。每股票日的同阶段历史和两日日内路径各编码一次，八时点从同一状态序列读出；[参考入口](v2201_predict_reference.py)独立逐时点计算。部分日内请求、动态股票池和无自身统计股票均保持原输出契约。

已经对非零阶段嵌入进行八时点未来梯度和参考一致性检查；仅初始零嵌入不足以证明此边界。本版没有执行真实全区间平台性能测试，不填写未经测量的加速倍数。

## 训练与资源

主收益 Huber delta=2、排名辅助权重 0.2、原专家分配／路由损失、时间权重及 EMA 保持父版设置。AdamW 学习率 0.0003、权重衰减 0.0001；EMA 0.9999、首轮预热。继续按验证 IC 选模，动态早停后冻结权重评估测试集，不按测试结果选择 epoch。

默认训练／推理 **64／128 股票日**，主机内存预留 **2 GiB**。共享输入缓存仍为训练 `c760f388…58563b`、验证 `b51e456d…52d800c`、测试 `749e20cf…da5`；[身份核对](../../experiments/v2201-input-cache-compatibility.json)确认数据定义、标签变换和原生加载源码一致，没有加载、修改或重建全量行情数组。

阶段组织发生在模型内，不新增全量输入缓存。网络变宽和新的递推路径会增加部分计算；CPU 默认宽度预检为 2 个训练、4 个推理股票日，三次优化步约 **0.50／0.42／0.42 秒**，参数梯度有限，输出 32 个 FP32 分数。这不是正式 GPU 吞吐或平台速度；GPU 默认批量仍由训练 session 检查。

若正式结果晋级，参数材料按 UTF-8 文本和单文件 50 MB 规则分片，保留完整精度及 fast 路径。当前没有生成未评测方案的提交材料。

## 实现验证

- [核心检查](../../tests/test_v2201.py)：默认参数与预留契约、非零嵌入下八时点因果梯度、共享／逐时点一致、每阶段独立递推参考、历史日不受当前日影响、前日晚段传到当前前缀、CPU BF16、原始权重／EMA／优化器／RNG 精确恢复。
- 同一个小规模宽度下，新增阶段表从零初始化，其他初始参数与容量匹配的父结构逐值一致，1 分钟路径输出相同。这用于检查结构复用，**不表示正式 v2201 与正式 v1601 容量或权重相同**。
- [完整合成入口](../../tests/test_v2201_entrypoint.py)：月度 FP32 与全局混合精度训练、共享缓存与原生输入一致、EMA 选模和双集完整输出；42 个主监督样本，未来目标口径不变。
- [平台合成检查](../../tests/test_v2201_predict.py)：非零阶段表、动态股票池及无自身统计股票；整日 24 行、部分 9 行，fast 与参考输出一致，没有查询标签或 `exposure`。

正式完成后比较父版／当前最优及可精确绑定的平台最优，报告验证、测试、各月与时点、距 0.25 的差距和成本。实现验证只证明本版可按声明运行，不能证明收益改善。
