# v701：宽 GRU、跨频交互与股票日联合训练

v70x 系列的首个组合方案，以 [v501](../v501/README.md) 为父版本和本地验证最优参照。run 为 `v701-wide-day-gru-s42`；一次正式训练及完整验证／测试已完成。验证 IC 未超过 v501，不默认导出平台材料。

## 设计依据

[近期论文与本地证据审查](../../docs/research-directions-20261021.md)支持优先保留原时间分辨率、原收益 Huber 主监督和 EMA，扩大表示能力并减少重复编码。v401 的排名监督改善 Rank IC、但降低 IC，因此作为独立辅助头加入；v306 的 delta=4 未改善，主损失保持 delta=2。论文只提供机制参考，不构成本项目收益证明。

本版同时调整结构、辅助监督与训练组织，只评价组合整体，不把结果归因于其中某一个改动。

| 部分 | 冻结设计 |
| --- | --- |
| 输入与预处理 | 沿用 v501 的 75 通道、固定交易日窗口、完整截面归一化和原时间分辨率 |
| 时序主干 | 每频两级单向 GRU，隐藏维度 96 → 256；原日内／跨日层数各 1 |
| 跨频交互 | 同股票同预测时点的三个频率 token，两个残差注意力／FFN 块；4 头，FFN 扩展 2 倍，残差尺度初始化 0.1 |
| 输出 | 融合宽度 512；收益主头和排名辅助头共用表示；评估及平台只输出收益主头 |
| 监督 | 主目标为原收益截面 zscore，Huber delta=2；辅助目标为平均秩 zscore，Huber delta=1，权重 0.2 |
| 权重选择 | 沿用 EMA decay=0.9999、首轮 warmup；按 EMA 的验证 IC 选模，动态早停 |
| 训练组织 | 全局随机股票日；每步 64 组、最多 512 个有效时点目标，组内保留全部现有时点 |
| 评估组织 | 每批 128 个股票日、最多 1024 个输出；FP32 共享编码，完整验证／测试键 |
| 参数量 | 3,878,662 |

AdamW、学习率 0.0003、梯度裁剪 1、dropout 0.1、随机种子 42 沿用父版本。配置以 [model-config.json](model-config.json) 为准。

## 共享计算与因果性

一次股票日取窗供八个预测时点使用：5／30 分钟历史和昨日 1 分钟表示共享，今日单向 GRU 从对应前缀读出。09:30 直接读取昨日跨日状态。跨频注意力只发生在同一个预测时点的三路表示之间，不在八个时点之间交换信息。

代表行选择该股票日实际请求中的最晚时点，输入由原窗口逻辑清除其后的 Bar；输出仅回填实际存在的键。缺失时点及无效标签不补成训练样本。收益和排名目标均先由完整截面生成，之后才打乱股票日。辅助向量单独保存来源记录，原行情缓存及原收益目标不改写。

训练共享投影和部分 dropout，使同组样本的随机性相关，批次相关性也不同于 v501，因此属于新的训练方案。eval 模式没有 dropout，共享路径与逐样本参考路径在逻辑上等价。正式验证使用共享路径，从训练设计阶段即适配 fast 部署。

恢复状态保存原始权重、EMA、AdamW、随机状态和 `group_cursor`；`sample_cursor` 为组游标的八倍，仅供既有进度工具展示名义时点数。`stock-day-training.json` 固定组成员、两类目标和来源指纹，恢复时核对。实际有效标签行数在历史记录中单独统计。

## 检查与成本

[针对性测试](../../tests/test_v701.py)检查双头共享／逐样本结果、逐时点未来梯度为零、缺失键和目标映射、实际组合损失、缓存主目标保持及精确恢复；[入口检查](../../tests/test_v701_entrypoint.py)用合成 Parquet 运行预处理、月度与全局股票日训练、完整验证／测试和流式评估缓存，并与独立逐样本预测对齐。CPU 默认规模预检确认全部参数梯度有限。

这些是实现检查；正式模型成绩另见下文。按用户的简化要求，不重复长行情区间的 fast 对照和性能基准；平台材料只在本地晋级后准备，权重精确恢复等检查仍保留。

扩容的计算量由股票日共享部分抵消。早期设计的 6—12 小时只是估计参考，正式实测低于该范围；仍执行现有动态早停，不强制跑满轮次。GPU 默认批量预检及正式训练由训练 session 执行。

## 冻结结果

2026-10-22（UTC+08:00）完成 seed 42 的单次正式运行，最佳为第 5 轮 EMA，连续四轮验证 IC 未创新高后停止，共 9 轮。验证 936,000 行、测试 1,000,000 行，全局和最低截面覆盖均为 100%，未定义相关系数截面为零。冻结权重 SHA-256 为 `20de738b8ee01b3dd2240737bf4e44b8719496666bfc43b871094178e1bdbb55`。

| 指标 | v701 验证 | 相对 v501 | v701 测试 | 相对 v501 |
| --- | ---: | ---: | ---: | ---: |
| IC | 0.086159 | −0.001040 | 0.091387 | +0.001056 |
| Rank IC | 0.084983 | +0.000964 | 0.087604 | +0.002519 |
| IC IR | 0.793373 | −0.009749 | 0.759137 | −0.012612 |
| Rank IC IR | 0.893742 | −0.005922 | 0.838046 | −0.000754 |
| 单向换手代理 | 0.640433 | 略高 | 0.635280 | 较低 |

v501 同时承担父版本与本地验证最优参照。验证和测试各有 3/6 个月 IC 提高、4/6 个月 Rank IC 提高；测试 IC 增益主要来自 11 月，不能解释为跨月一致改善。测试 IC 和双集 Rank IC 的提高不改变验证 IC 晋级规则，暂不新增提交目录。可信平台最佳 run／权重对应关系仍缺失，平台差值未知；该测试期已经在持续研究中观察过。

RTX 4080 上九轮训练及验证累计 5,779.327 秒（约 96.3 分钟），平均每轮 642.147 秒；v501 的对应总计为 12,719.937 秒、12 轮，平均每轮 1,059.995 秒。模型约 388 万参数，整体方案在扩大网络的同时缩短了实测单轮耗时，但结构、组织与执行路径共同变化，不能把时间比归因于单个组件。全运行墙钟 7,947 秒，含资源保护中断及等待，不作为纯训练时间。

原运行从保留的优化器、EMA、随机状态和游标恢复，未新增种子或正式训练尝试。恢复时仅将执行包装器的 CUDA 缓存分配比例从 0.8 调为 0.25，保持研究配置及 8 GiB 内存保护；冻结权重的两次完整验证对照覆盖 936,000 行，预测、截面和汇总指标完全一致。最终摘要区分累计九轮时间和最后恢复段时间。

完整比较及资源口径见[冻结摘要](../../experiments/v701-gru.json)，换手与持续性见[信号诊断](../../experiments/v701-signal-diagnostics.json)。[分预测时点比较](../../experiments/v701-clock-comparison.json)显示若干时点的验证／测试 IC 差值方向相反，不支持据此手工选择不同模型的输出。换手代理没有复刻平台交易成本模型，单种子结果不证明统计显著。
