# v1501：完整市场时空 Transformer

v150x 系列首版，检验独立股票序列是否遗漏了跨股票、跨时点的市场信息。run 为 `v1501-market-space-time-s42`，seed 42，从头初始化，**3,141,398** 个可训练参数。网络不含 GRU，不继承父模型权重。工程代码来源是 v1301 的整日加载及恢复设施，`parent_run_id=null`；效果参照是已完成的 v1401 和单主干 v1102，不使用在训版本的未知成绩。

本版已完成正式训练和双集评估，未达到改善条件，不导出平台材料；结果见[冻结结果](#冻结结果)。

[研究依据](../../docs/market-space-time-research-20261022.md)结合了 MASTER、2026 年 CRAFT／MSTAN／STABLE 的机制与局限，以及[本地组合诊断](../../docs/portfolio-diagnostics.md)。本地换手代理尚不能可靠代表平台分项，因此本版优先研究市场时空表示，未将该代理设为主优化目标。

## 网络与数据组织

| 部分 | 冻结设计 |
| --- | --- |
| 原始输入 | 75 通道，1／5／30 分钟窗口 480／288／168，均包含当天因果前缀；既有 FP16 输入契约 |
| 序列编码 | 每频两层因果 Patch Transformer，宽度 128、四头注意力、FF 倍数 2；Patch 大小 6／2／1，对应 80／144／168 个 token |
| 归一化与残差 | 每 token 的 pre-LayerNorm，残差尺度初值 0.1，dropout 0.1；保持原输入缺失标志 |
| 市场时空交互 | 三频和八时点 one-hot 融合为 256 维；两轮完整股票轴注意力与因果时点轴注意力 |
| 成员 | 当时股票池决定上下文，不使用股票身份嵌入、行业或手工关系图；无标签股票也保留 |
| 输出与损失 | 收益／排名两头；收益 Huber delta=2、排名 Huber delta=1 权重 0.2、稳定化相关性权重 0.2，分母平滑尺度 0.02 |
| 优化与选择 | AdamW 0.0003，EMA 0.9999 对应 64 股票日、首轮 warmup；全训练日期归一化的时间权重、验证 IC 选模、统一动态早停 |
| 计算组织 | 整日更新，预检批量上限 1200 股票日；序列编码块 64，训练时重计算；市场交互在完整当前股票池执行 |

精确设置见 [model-config.json](model-config.json)。本版同时改变骨干、市场交互和训练上下文，只评价整体方案。v801／v802 先前失败不等于本方向已被否定；本版若失败，也不能据此宣称所有市场联合方法无效。

原始股票池有 970 个训练日、97 万股票日；新训练上下文保留全部股票日，收益监督仍只有原规则下的有效位置。一个股票没有有效标签，不会从其他股票的市场上下文中消失。仅当整个日期没有可训练标签时跳过该日期。股票日分组、成员和目标分别留指纹，恢复时核验日期游标、累计上下文股票日数与 EMA。

## 因果性与 fast 推理

Patch 不跨越预测截点，序列注意力严格单向；股票轴只允许当前时点成员，时点轴不读取未来状态。每频因果前缀只编码一次，从相应位置取出八个时点。股票编码块大小只控制计算资源，不能改变联合预测的股票集合。

平台推理按完整交易日上下文处理。即使只请求 10:30—11:30，也先重建当天此前时点的股票池和市场状态，包括 10:30 前退出的股票，最终只返回请求键。此方式不依赖前一次调用，支持拆分日期／时间请求的一致性。两个推理入口均使用这条 fast 路径。

单个市场时点使用完整股票注意力，计算量包含股票数的平方项；不会用低秩近似冒充已实现的全股票交互。默认完整规模的 GPU 显存与耗时由训练 session 在模型间隙预检，CPU 小批量检查不代表吞吐。参数文件若超过单文件限制，应完整精度分片，不为减少附件数量缩小模型。

## 已完成实现检查

- 八项[模型检查](../../tests/test_v1501.py)：默认规模、三频八时点未来梯度隔离、未来成员隔离、股票置换、编码分块、无标签上下文、FP32／CPU BF16 重计算以及精确恢复。
- [全局缓存完整入口](../../tests/test_v1501_entrypoint.py)：三个合成训练日，17 个上下文股票日、其中16个有监督股票日、112个有效标签；FP16缓存、日期双缓冲、EMA选模和双集输出通过。
- [日内部分请求](../../tests/test_v1501_predict.py)：动态股票池中，早先退出股票仍参与过去状态，部分请求与整日对应结果一致。

上述检查为 CPU 合成验证，不能代替正式行情效果或平台分数。[缓存身份核验](../../experiments/v1501-input-cache-compatibility.json)使用 v1002 冻结清单确认相同训练缓存键，仅读元数据、未加载或修改行情数组；正式运行另核对自身指纹。实现检查与代码指纹见 [readiness](../../experiments/readiness/v1501.json)，发布配置见 [experiment.json](experiment.json)。

## 冻结结果

一次正式运行，按验证 IC 选中第 **5** 轮 EMA，共完成 **9** 轮，连续四轮未改善后早停。权重 SHA-256 为 `3a17c3e665a42f33ac3bf2bdd5f865f36c38e1a1ae8611d1296d11d097f8cf5a`。完整指标、逐月差值、来源指纹及资源记录见[冻结摘要](../../experiments/v1501-patch-transformer.json)。

| 模型／参照角色 | 验证 IC | 验证 Rank IC | 测试 IC | 测试 Rank IC |
| --- | ---: | ---: | ---: | ---: |
| v1501 | 0.079530 | 0.078322 | 0.078641 | 0.079418 |
| v1401：整体本地最优、设计参照 | 0.093062 | 0.091252 | 0.099979 | 0.093134 |
| v1102：单主干最优、设计参照 | 0.092474 | 0.090069 | 0.098965 | 0.089146 |
| v1301：代码来源，补充比较 | 0.085884 | 0.080454 | 0.090892 | 0.080599 |

相对单主干最优 v1102，验证 IC／Rank IC 下降 **0.012944／0.011747**，测试下降 **0.020323／0.009728**。相对 v1102 和 v1401，验证六个月、测试六个月的 IC／Rank IC 全部下降。相对代码来源 v1301，验证 IC／Rank IC 分别有 1／2 个月改善，测试分别为 0／1 个月，整体仍下降；它不是本版设计时已完成的父模型。

本版双集 IC IR 为 **0.736442／0.712382**，Rank IC IR 为 **0.823369／0.773160**。预测覆盖完整、有效标签样本数为 **935,224／998,539**，未定义相关性截面均为零。训练每轮保留 **970,000** 个上下文股票日，其中 **967,872** 个有监督，实际有效标签数 **7,742,958**；无标签成员、完整日期、EMA 单位、源码及双集产物均已核验。MSE／MAE 保留在摘要，标准化目标单位不作为收益校准证据。平台观测尚未精确绑定本地 run／权重，平台最优比较仍缺失。

RTX 4080 上九轮训练及逐轮验证合计 **90.11 分钟**，平均每轮 **600.75 秒**，总墙钟 **95.18 分钟**。每轮比 v1301 的 777.95 秒更短，但模型和收敛轮数不同，不是单组件速度消融。[本地换手代理](../../experiments/v1501-signal-diagnostics.json)为验证 **0.657405**、测试 **0.645103**，均高于 v1102 和 v1401，不能据此支持改变未晋级结论。

第 5 至 9 轮，训练中 raw 权重的稳定化相关性从 **0.105512** 增至 **0.128507**，EMA 验证 IC 却从 **0.079530** 降至 **0.074959**。训练统计与验证来自不同权重和样本，但该趋势不支持简单延长当前设置。骨干、Patch、市场交互和训练组织同时改变，不能将退步单独归因于跨股票注意力。

**不导出，不自动继续扫描本系列的宽度或注意力层数。** 后续优先检验[盘前信息覆盖缺口](../../docs/session-input-research-20261022.md)，v1601 和 v1701 保持已发布配置。单种子结果不代表统计显著性，测试区间已被持续研究观察。
