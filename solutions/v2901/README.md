# v2901：保留相对输入并恢复数量绝对尺度

v290x新系列首版，run为`v2901-quantity-units-s42`，直接父版为v2401。完整保留父77通道及因果历史，从seed42重新训练；增加22个近似绝对数量值和22个独立有效标志，总输入121通道。共 **2,834,517参数**，比父版增加192,774，约7.30%。2026-10-24（UTC+08:00）已完成实现检查并发布ready。正式比较还须面对已完成的最新最优v2801；当前没有本版收益结果。

## 机制及证据边界

[研究依据与训练期审计](../../docs/normalization-information-research-20261024.md)确认，既有数量z使用各股票字段自己的均值与尺度，数量c又对z做截面标准化。固定参数已知时变换可逆，但模型没有直接接收这些参数。本版用它们补充数量单位视图，让网络学习绝对成交量、金额和盘口数量与原相对输入的交互；没有构造量额比、成交均价或新的收益标签。

v2001已检验共同盘口数量坐标且整体失败，同时替换了原c；本版保留全部原c和z。v2701检验三个遗漏字段，但尚无完整结果；本版不增加它的成交笔数、前收盘价和复权因子。v2801则更换预测器，本版仍重新训练神经网络，独立检验输入信息假设。

固定统计必须满足原预处理的计数和尺度阈值。对可信字段，用父版实际解码的z和冻结参数执行FP32乘加，近似恢复`log1p`数量，将微小负舍入值截为零，再统一除以10。新标志要求原z有效、固定统计可信且Bar位于当前已知前缀。均值和尺度只用于该反变换，不作为额外股票身份特征直接拼入网络。

合法零值可能有微小正舍入残差，因此不声称逐位恢复或用严格等零识别零成交。未知股票、恒定或观测不足的字段只将新增视图及标志置零，原输入和样本继续保留。价格字段缺失不会清除同Bar仍有效的数量视图。收益监督继续直接使用已提供`vwap_return`的原标准化／排名加工，不读取exposure。

三频各增加两个128维共享MLP：分别投影到原192维时序输入和64维历史内容表示，在后续非线性前参与交互。输出层零初始化、残差尺度初值0.1，初始化时父参数和预测保持。完整三频GRU、价格历史读取、四专家、Huber／排名目标、日期权重、EMA和验证IC早停保持。

## 缓存和效率

[缓存身份核对](../../experiments/v2901-input-cache-compatibility.json)直接重建并确认仍复用父价格历史缓存：训练`d35c64fd…`、验证`925385ed…`、测试`9921f36a…`。没有新建完整行情数组、归一化Parquet或目标数组。

训练参数表为931,392字节，约0.89MiB；验证和测试各582,384字节。它们按当前缓存股票顺序从已冻结统计中生成，未知统计以零尺度标记。取批时才在GPU或CPU完成反变换，父72个存储数值和FP32价格中心保持原字节。常驻／流式原数组的选择沿用父机制，缓冲预算按121通道计算，主机预留 **2GiB**。

正式训练／推理仍为64／128股票日。CPU默认宽度预检使用2／4股票日，合成更新约0.543／0.313／0.308秒；不将这些时间外推为完整GPU训练成本。GPU默认批量及实际峰值由训练session检查。
