# v3201：持续字段节点的时空编码

[研究与论文审查](../../docs/field-grid-research-20261024.md) · [配置](model-config.json) · [候选登记](experiment.json)

v320x开启日内字段状态组织系列。结构父版为v2401，从种子42重新初始化，一次正式运行；使用2026-10-24修订数据。v2401只提供结构来源，不重训旧模型，不直接计算跨快照分数差。

## 核心变化

原v2401先在单根Bar内处理五档盘口，合并为一个向量后再进行时间递推。本版让五档盘口及一个非盘口节点在日内持续保持各自的状态，并在两次时间递推之间交换信息。原映射没有被证明丢失信息，本版检验的是不同的结构组织，不能预先称其为已确认瓶颈。

| 部分 | v3201设计 |
| --- | --- |
| 输入 | 沿用77通道及1／5／30分钟480／288／168 Bar，不缩短历史、不新增手工因子 |
| 盘口节点 | 五档，各含买／卖价格、数量、订单数的两种已有视图与标志；共享14→64投影 |
| 非盘口节点 | OHLC、成交量／额的两种视图及标志；独立14→64投影 |
| 第一次时间递推 | 六个节点共享64维单向GRU参数，各自保留隐状态，按交易日重置 |
| 同Bar空间交互 | 六节点、四头注意力和两倍宽度前馈；不跨股票、不跨时间归一化 |
| 第二次时间递推 | 另一个节点共享64维单向GRU，继续分别维护节点状态 |
| 日内读出 | 六节点拼接，384→192；另加原75通道的线性直接路径 |
| 跨日及预测 | 保留192维跨日GRU、完整价格历史读取、三频融合及四专家收益／排名头 |

两次时间递推各自的总节点状态宽度为384。参数在节点间共享，不把五档标准化后的数值当作等距物理价格网格，也不从分钟快照重建逐笔提交、撤单或成交事件。

未来槽位在原入口清零，空间混合只发生于同一Bar，两个时间阶段均单向。09:30读取昨日跨日状态；后续时点仅接入当前已闭合的前缀。缺失槽位及已有标志保留，不因盘口不完整清除其余有效数值。fast执行共享完整股票日编码，各查询分别读取自身因果状态。

## 训练与效率

保持原提供`vwap_return`的标准化／排名、时间权重、Huber及专家／路由损失；AdamW、EMA、动态早停及验证IC选模不变。验证选定权重后完成测试评测，不使用exposure，不叠加尚无正式结果的v3001或v3101机制。

参数总量 **2,352,408**，比v2401减少289,335，约 **10.95%**；每频日内字段网格173,955参数。节点共享的小GRU减少参数，却增加递推阶段和中间状态，不能据参数量宣称加速。

默认训练64、推理128股票日，主机内存预留 **2GiB**。输入语义和新快照缓存键与v3001一致，见[缓存兼容性证据](../../experiments/v3201-input-cache-compatibility.json)，不新增完整行情／目标数组；该证据不判断在训缓存是否完成或调度来源验收状态。新运行使用[路径解析器](../../scripts/training-data-paths.py)取得修订数据的三个显式路径，正式调度及GPU预检仍由训练session负责。

## 已完成实现检查

11项CPU检查通过，合计40.739秒：节点批量递推与独立计算的值／梯度一致；字段和标志映射；已知均值空间注意力；日边界与时间前缀隔离；全缺失及部分缺失；八时点未来梯度为零；BF16有限梯度；文本权重精确恢复；原始权重、EMA、优化器及RNG断点恢复；月内／全局完整合成训练和双集评测；动态成员及部分请求fast一致性。

默认网络宽度的CPU预检使用训练2、推理4股票日，三个训练步约0.59—0.67秒，全部参数梯度有限；这不是正式GPU速度或总训练时间预测。隔离目录中的训练源码及Notebook推理依赖可独立导入。平台仅在正式晋级后生成fast附件，不重复长行情或速度基准。

目前无正式收益结果。盘口时空结构在逐笔分类上的论文证据不能直接证明分钟截面IC改善；本次整体替换日内编码，结果也不能单独归因于节点宽度、空间注意力或递推层数。完整结果将在新数据组内比较，并同时报告Rank IC、月份、时点和实际资源成本。
