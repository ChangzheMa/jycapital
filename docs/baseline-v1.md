# v1：原始量价序列 MLP 基线

[文档目录](README.md) · [配置](../solutions/v1/config.json) · [评估约定](development.md)

冻结运行 `v1-20261010-s42`，seed=42，选中第 8 轮权重。模型源代码位于 [solutions/v1](../solutions/v1/)。

## 方法

| 项目 | 设置 |
| --- | --- |
| 输入 | 5 分钟 OHLC、volume、amount |
| 窗口 | 最近 12 条已结束常规 Bar，最长回看 20 个日历天 |
| 网络 | 展平 72 维 → Linear(64) → ReLU → Dropout(0.1) → Linear(32) → ReLU → Dropout(0.1) → Linear(1) |
| 参数量 | 6,785 |
| 训练标签及损失 | 官方 vwap_return，训练目标裁剪至 ±0.1 后乘 100，Huber delta=1 |
| 优化器／batch | AdamW：学习率 0.001、weight decay 0.0001；batch 8,192 |
| 选择与停止 | 验证 Rank IC 选模，min_delta=1e-5，耐心 3 轮，上限 12 轮 |
| 推理 | NumPy，返回有限 float64；不读取标签或风险暴露 |

保留上午 `(09:30,11:30]`、下午 `(13:00,15:00]` 的真实 Bar 序列。非有限值、非正价格和负数量视为缺失；只取已发生的历史，不向未来填充。

OHLC 除以窗口最后有效 close 再减一，volume／amount 分别除以窗口有效均值再减一。结果裁剪至 ±10，缺失及不足历史补零；全无历史也由同一网络预测。归一化只依赖当前历史窗口，评估保持原始标签。

## 冻结结果

| 划分 | 有效标签 | IC | Rank IC | IC_IR，未年化 | 最低截面覆盖率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 训练 | 7,742,958 | 0.084225 | 0.080082 | 0.778969 | 100% |
| 验证 | 935,224 | 0.070445 | 0.061333 | 0.566824 | 100% |
| 测试 | 998,539 | 0.083549 | 0.068316 | 0.591439 | 100% |

训练／验证／测试分别有 7,760,000／936,000／1,000,000 个预测键，全部有有限输出。训练首截面无更早历史、预测恒定，IC 无定义；验证／测试没有未定义截面。测试 MSE 为 `2.2055884e-5`，零预测参照为 `2.2081764e-5`。

PyTorch／NumPy 推理及原始行情完整测试半年预测的一致性已核验。完整指标、验证范围和权重指纹见 [结果摘要](../experiments/v1-baseline.json)；平台状态见 [提交索引](../submissions/README.md)。

## 使用与提交

训练环境、独立运行及结果边界按[开发约定](development.md)。v1 使用不同的训练入口：

```powershell
.venv-training/Scripts/python.exe -u solutions/v1/v1_train.py --run-dir outputs/runs/v1-new-run
```

`--prepare-only` 可先准备缓存，随后以相同目录开始训练；校验源码、配置和数据指纹，开始训练后不能复用目录重新训练。

平台材料及 NumPy 推理依赖见 [提交目录](../submissions/v1-20261010-s42/README.md)。
