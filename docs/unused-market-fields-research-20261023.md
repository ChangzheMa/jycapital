# 遗漏行情字段与价格参考的研究决策

[文档目录](README.md) · [双集IC目标](ic-target-research-20261023.md) · [价格历史读取](price-path-research-20261023.md)

检查与论文访问日期：2026-10-23，UTC+08:00。当前最优[v2401](../solutions/v2401/README.md#冻结结果与平台材料)验证／测试IC为0.107778／0.119352，距离双集0.25仍远。本轮先检查现有输入清单的遗漏；没有训练新模型，没有读取标签、使用exposure或修改任何已发布方案。

## 已确认的输入缺口

官方[分钟字段资料](bigquant-2026-end-to-end/data.md#3-分钟行情字段赛事页公布的-1-分钟表)列出42列；当前主线的36个原始数值字段之外，还存在三个未使用的数值字段和一个身份字段。它们不是新增外部数据，也不是从收益标签反推的特征。

| 字段 | 官方含义 | 当前判断 |
| --- | --- | --- |
| `deal_number` | 成交笔数 | 与五档盘口`ask_num_orders*`、`bid_num_orders*`含义不同，值得检验成交事件数量信息；不是标签表未来窗口的`num_trades` |
| `pre_close` | 前收盘价，官方未展开前一日／Bar口径 | 样本内为日级常量；与上一日原始close存在差异，不能直接视为普通相邻Bar字段 |
| `adjust_factor` | 复权因子 | 样本内为日级常量；变化与前收盘参考差异同日出现，但不足以据此决定整段行情的复权规则 |
| `instrument_id` | 股票数值ID | 身份元数据，不能把任意编号大小当连续经济量；本轮不构造身份嵌入 |

已有[data-validation](bigquant-2026-end-to-end/data-validation.md)注明实际`deal_number`为int64、个别月份存在复权因子缺失。本文不改变104条官方字段字典，不把固定样本的完整性外推为全量无缺失。

## 训练样本证据

[审计脚本](../scripts/audit-unused-market-fields.py)复用既有价格审计预先固定的2020—2023年各六月前五交易日、每年64股。首日仅提供前日对照，主诊断为16日、1,024股票日；三频共303,101条规则Bar。[结果与来源指纹](../experiments/unused-market-fields-audit-20261023.json)记录抽样内容散列和父版源清单哈希，未重读整月计算哈希。没有训练或验证／测试选字段。

| 诊断 | 1分钟 | 5分钟 | 30分钟 |
| --- | ---: | ---: | ---: |
| 样本Bar数 | 245,757 | 49,152 | 8,192 |
| 成交笔数有限且非负整数 | 100% | 100% | 100% |
| 成交笔数中位数 | 32 | 184 | 1,200.5 |
| 成交笔数为零的Bar | 5,056 | 6 | 0 |
| log1p成交笔数与log1p成交量相关性 | 0.8371 | 0.8197 | 0.8065 |
| pre_close或adjust_factor日内变化的股票日 | 0 | 0 | 0 |

完整的49,149个5分钟区间、8,189个30分钟区间，其成交笔数与对应1分钟加总均逐值相同，成交量也相同；缺失1分钟槽位的区间排除，未推断盘口聚合规则。所有频率中，26／1,024股票日的pre_close不同于上一有记录日原始close，这26日也恰好是adjust_factor变化日。该关联支持单独处理日级参考，尚不能确认官方复权计算方式或标签公式。

成交笔数与成交量高度相关但不相同，不代表已证明条件独立的信息增量；必须由正式收益任务检验。未构造成交均价、均笔金额、手工盘口指标或任何新的收益标签。合成前日与相邻Bar对照检查已通过，正式源行情保持只读。

价格去中心论文支持继续区分“信息是否保留”和“网络是否容易利用”，不支持照搬整个窗口的未来统计。v2001已经检验可学习因果归一化且整体失败，不能忽略这一负结果；但该版同时替换数量c，其归一化主要作用于行内价格几何及数量组，与保留全部父输入、显式组织价格时间路径并不等价。v2401仅提供小幅新正证据，不能把相近模块都当成未探索的大方向。

## 下一候选应检验的机制

优先检验**成交过程信息与日级价格参考能否补足当前输入组织**，而非继续扫描GRU宽度、历史长度或注意力头数。新设计应保留已有有效父输入和完整历史，增加已闭合Bar的成交笔数及明确可用的日级参考，让网络学习它们与价格、量额、盘口之间的交互。价格偏移去除与尺度缩放须有明确区别，不用未知复权规则替换原始价格；保留提供的vwap_return及原正式评估口径。

设计发布前还需落实两点：新增字段与现有网格的时间／成员对齐、独立字段缺失时的保持策略；训练只拟合训练区间的新统计，并通过旁路复用现有输入，避免重复数十GiB缓存。09:30不能借用首根尚未闭合Bar中的当日参考，后续时点也只能读取各自已知前缀。新增版本继续预留2GiB，按容量阈值登记，正式训练由训练session串行安排。

v2501的同日后续收益监督、v2601的原始全市场条件已分别发布，继续作为独立机制检验。它们尚未有完整结果时，不将其模块默认叠加进新候选。下一版是否晋级仍由正式验证IC、完整覆盖及冻结测试结果决定，输入审计和论文均不代替收益证据。
