## 新增方向很小，而且存在原方向稀释

逐截面对中心化父预测\(p\)、新预测\(q\)求分解，令\(d=q-p\)：

\[
\beta=\frac{p^\top d}{p^\top p},\qquad r=d-\beta p,\qquad q=(1+\beta)p+r,\qquad p^\top r=0.
\]

这里的投影系数仅由两组预测计算，没有使用标签拟合校准器。对于中心化标签\(y\)，IC变化可精确写为：

\[
\Delta IC=\frac{r^\top y}{\|q\|\|y\|}
+\left(\frac{(1+\beta)\|p\|}{\|q\|}-1\right)IC_{\mathrm{parent}}.
\]

| v2801相对v2401 | 验证 | 测试 |
| --- | ---: | ---: |
| 平均截面预测相关性 | 0.990438 | 0.988443 |
| 与父方向正交部分占新预测方差 | 1.896% | 2.286% |
| 正交部分的IC贡献 | +0.001378 | +0.002231 |
| 原父方向归一化贡献的变化 | −0.000807 | −0.001031 |
| 合计IC变化 | +0.000571 | +0.001200 |

因此变化不是纯粹的正向线性缩放；但“不与父分数线性重合”不等于加入了新的原始信息。两版分数差包含冻结推理路径的浮点差异，本分析不将它逐行强称为原生树输出。保持这一边界，正交分解仍精确还原实际冻结预测的IC差值。

## 树实际使用的输入与不确定性

选中25棵树共1,332个分裂，使用362个不同特征。训练分裂增益中，父网络融合表示占 **74.26%**、父预测占 **17.68%**，合计91.94%；剩余为价格坐标、数量视图及14:30时钟。25个根分裂中22个使用融合表示、3个使用父预测。直接的绝对对数价格中心及可用性标志没有被选中。

这说明当前树主要在已有神经表示和主分数上工作，未发现大量依赖此前忽略原字段的新机制。分裂增益是训练统计，相关特征可互相替代，**不等于样本外贡献或因果重要性**；不能由零次分裂推断某个字段普遍无用。

另将每日八时点差值取均值，以固定5个交易日连续块、固定种子20261024做2,000次探索性重采样。v2801的IC增量95%百分位区间为验证 **[−0.000358，0.001823]**、测试 **[−0.000097，0.002774]**，均跨零；Rank IC变化区间均在零以下。v1601和v2401的IC增量区间均在零以上。重采样没有校正验证选模及长期研究观察，因此这些区间只用于描述稳定性，不能作为独立显著性证明，也不增加新的候选晋级门槛。
