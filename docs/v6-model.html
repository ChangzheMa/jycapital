02

完整连接：先在各频率内计算，再做一次融合

箭头表示前向数据流。四路网络拓扑相近，各自持有权重；所有股票使用同一套四路编码器。各分支在池化前互不交换特征。

所有卷积 stride=1，时序长度 T 始终不变。每条投影后有 GELU 与 valid 掩码；每路池化线性层后也有 GELU。图中的 d 为 dilation（膨胀率）。

选择步骤可查看输入／输出形状与对应代码；“下一层”依次走完当前分支及公共预测头。这里只演示结构，不加载模型权重，也不运行真实行情预测。

03

展开一个残差块：主路算两次，旁路保留输入

13 个残差块都使用下列连接。块内两个卷积的膨胀率相同，权重独立；块与块之间才将膨胀率翻倍。

CausalBlock · 输入与输出均为 [B, 160, T]

每块 154,560 个参数

① 左补零 + 膨胀卷积

每次卷积前在时间轴左侧补 2 * d 个零，右侧不补。kernel=3、stride=1：位置 t 只读取上一层的 t、t−d、t−2d，同时混合全部 160 个输入通道。输出仍是 T 个时点。

② LayerNorm 归一化哪个轴？

先从 [B,160,T] 转成 [B,T,160]，对每个样本、每个时点的 160 通道归一化，再转回。不同时间点、不同股票不会在该层一起求均值；它不会因归一化读取未来时点。

③ GELU → Dropout → valid

GELU 加入非线性。训练时普通 nn.Dropout 逐元素以 0.35 概率置零，保留项除以 0.65；同一 Dropout 模块调用两次会各自采样。推理时原样通过。随后用 [B,1,T] 的 valid 广播到全部通道，将无效位置清零。

④ 主路和原输入逐元素相加

两路都是 [B,160,T]，因此可以直接相加，无需额外投影。相加后再乘 valid，随即交给下一块；没有拼接，也没有相加后的额外激活。旁路让输入直接传递，同时主路学习需要补充的变化。

residual = h
for conv, norm in zip(convolutions, norms):  # 共两次，d 相同
    h = conv(left_pad(h, 2 * d))
    h = norm(h.transpose(1, 2)).transpose(1, 2)
    h = dropout(gelu(h)) * valid
output = (h + residual) * valid

04

把一段序列，收成一个 160 维向量

TCN 输出仍是 [B,160,T]。每路 FrequencyEncoder 用两种方式沿时间轴读取，再经过一个学习到的线性投影。

last 与 mean 是并行读取

last：查找 valid=1 的最后一个位置，从 TCN 输出取出该位置的全部 160 通道。它可能早于窗口最后一格。

mean：将所有时点的隐藏向量求和，再除以有效 Bar 个数。无效位置此前已经被清零；分母至少取 1。

先 last 后 mean，沿特征轴拼接成 320 维，再用 Linear(320,160) 和 GELU 压回 160 维。每个频率拥有自己的投影参数。

这个输出代表什么？

最终线性层后没有 sigmoid、tanh 或截面 softmax，因此分数可正可负。squeeze(1) 只移除末尾的单元素维度，输出变成 [B]。

训练目标是未来 30 分钟的官方 vwap_return，但纯 IC 损失不约束预测分数的均值与幅度。除以 100 是固定缩放，不能把 factor 直接解释成经过校准的收益率。

最终返回 date、instrument、factor，factor 转为 float64。若四个分支全空，预测时钟及预测头偏置仍可产生非零分数；“空分支归零”不等于“最终输出归零”。

读图时最容易混淆的几个地方

这是 Transformer 或跨股票注意力模型吗？

模型由 Conv1d、LayerNorm、GELU、Dropout 和 Linear 组成，没有 attention。神经网络的前向计算逐股进行，batch 维不参与卷积或 LayerNorm 混合。不过输入 c 使用股票池截面统计，训练 IC 损失也联系同一时点各股票的预测。

投影 77→160 会压缩时间吗？

不会。1×1 Conv1d 在每个时间位置把 77 通道变成 160 通道，只混合该时点的输入特征；时间长度不变。接下来的 kernel=3 卷积才混合不同时间位置。序列长度直到 last／mean 池化时才被消去。

残差相加和拼接有什么区别？

残差相加要求形状相同，160 通道加完仍是 160 通道。last 与 mean 的拼接把两份 160 维并排放成 320 维；四路融合再把四份 160 维和时钟 2 维并排放成 642 维。拼接本身没有参数。

为什么 Dropout 增加，参数量没有增加？

Dropout 不保存可训练的权重或偏置，只在训练时随机置零部分元素，并调整保留项尺度。概率从 0.10 改为 0.35 不改变网络的层宽与连接。LayerNorm 在推理时仍按当前时点的通道计算；Dropout 在 eval 模式关闭。
