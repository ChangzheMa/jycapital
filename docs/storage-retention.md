归一化文件把 36 个输入字段各保存为 `z`、`c` 两路，共 72 个 FP32 数值列，再附日期及股票键。`c` 是对 `z` 的截面标准化。它们已用 ZSTD level 3 压缩，不是未压缩 CSV。打包缓存进一步按股票／交易日去重、筛取实际所需历史并保存 FP16 及 FP32 极值例外，避免每轮重复切窗和读取 Parquet。两层资料用途不同。

当前 v1301 与 v1501 共享 `resident-cache/dbcd47ff…`，单纯新增这两版不需要各增加一套 38.7 GiB 训练缓存。它们各自的评测缓存键不同，按现实现完整评估预计各增加约 9.85 GiB；这是依照相同数据布局估算，实际以建成目录为准。epoch 增加通常复用缓存，不会每轮复制全量输入。

确切路径和大小保存在本地 `outputs/checks/continuous-research/storage-cleanup-plan-20261022.json`，完整文件盘点在相邻的 `storage-inventory-20261022.json`。这些是会过时的本机状态，不纳入 Git。执行时应按具体目录核对，不用通配符删除整个 `evaluation-cache/`，因为训练可能已在其中创建新的缓存。

旧训练缓存 `resident-cache/f8d65a30…` 另占 **38.73 GiB**，暂列有条件清理。控制器仍将它作为启动参数；当前入口看到其旧 manifest 后才转到 `dbcd47ff…`。若直接删掉旧目录，后续启动会失去这项判断并可能重新构建大缓存。应先由训练调度方调整启动参数，再清理完整旧目录；不制造“manifest 显示 complete、数组已删除”的残缺缓存。两批合计约 **114.89 GiB**。

四频预处理中仍有约 8.66 GiB 的 `bar15m`，当前三频候选不消费它，但历史四频模型复现会使用。它不在优先清理清单内，可在接受旧版本重建成本后另行归档。

## 保留边界

- 原始 `data/`、当前三频预处理、最终归一化统计及处理记录，仍用于新任务的数据校验、缓存构建和原始输入研究。
- 当前训练缓存 `dbcd47ff…`、正在训练及待训练版本的评测缓存、当前运行断点和控制状态必须保留。
- `outputs/runs/` 中所有 `best.pt` 合计约 0.36 GiB，完整预测约 0.52 GiB，保留其研究价值。`last.pt` 合计约 1.15 GiB，其中还包含活跃任务，不将整个目录当作垃圾清理。
- `solutions/`、`experiments/`、正式 `submissions/` 和 Git 历史保持可追溯；环境和认证配置不作为常规清理目标。
- `outputs/run-control/continuous-research/execution/*/project/` 有指回 `data/`、`outputs/` 的 Windows junction。它们不是行情副本；禁止通过递归进入这些联接清理真实目标。

## 减少后续增长

第一优先级是把评测输入缓存与模型版本分开。v901、v1002、v1101、v1102、v1201 的验证数组清单彼此相同，测试数组清单也彼此相同：逐文件大小和已保存 SHA256 全部一致，但版本私有构建器源码指纹不同，生成了五组不同目录。这里仅比较已有清单，没有重读大数组做全量核验。

后续可为新版本统一稳定的预处理与打包实现，让缓存身份绑定实际数据、划分、输入语义、精度和实现版本；网络宽度、损失或模型名称不应单独导致输入复制。源码指纹仍应保留用于追溯，不能为了复用而跳过真正的数据差异检查。已发布／正在运行版本保持冻结。

同时应按依赖保留缓存：活跃和排队模型引用的缓存保留，已完成模型的可重建缓存按容量清理，正式权重与预测长期保留。当前只记录建议，尚未修改另一 session 的控制器或启用自动删除。

进一步压缩 Parquet、为数组采用无损分块压缩、将冷数据移至其他磁盘，均可评估，但需分别验证数值恢复、读取吞吐、峰值内存及路径指纹。现有 Parquet 已压缩，额外收益不能预先承诺。继续降低数值精度会改变输入，不能当作无损空间优化；也不改变已提供的 `vwap_return` 或引入 `exposure`。

只读重新盘点：

```powershell
.venv-training/Scripts/python.exe scripts/audit-storage.py --output outputs/checks/storage-inventory.json
```

该工具跳过所有 reparse point，不读取行情内容，不删除文件。清理判断还需要结合当时运行状态和依赖关系，不能仅根据目录名称自动决定。
