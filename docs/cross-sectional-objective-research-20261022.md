## 本地证据与关键问题

[v4](../solutions/v4/README.md) 的纯 Pearson 训练相对 v3 改善，但未超过当时最优，且输出幅度失去校准。[v7e](../solutions/v7e/README.md) 的完整截面标签标准化与随机 Huber 训练提高验证表现；后续 v303、v501、v1002 延续点监督获得改善。这支持保留 Huber 锚点，不能简单回到纯相关性损失。

当前随机股票日 batch 混合多个日期。对整个 batch 求相关性会混合时间与截面变化，不能解释为比赛的截面 IC。若改成一整日一个 batch，原先 batch 内归一化的时间权重全部相同，会被约掉；因此本轮同时调整数据组织、时间权重归一化及 EMA 的衰减单位。

## v1301 组合设计

开启 v130x 完整截面目标与训练组织系列。以 v1002 的输入、单个共享主干和多分支头为基础，从头训练，保持参数量和平台 fast 推理结构。

- 每个更新包含一个训练交易日的全部合格股票日，八个时点独立计算截面目标；保留全部原有有效标签，不用小子集相关性代替完整截面。
- 每 64 个股票日为一个网络计算块，使用 activation checkpoint 保存随机状态；汇总所有块的预测后计算完整损失，反向重计算各块。输入传输继续双缓冲，限制中间激活规模，不降低原始时间分辨率。
- 保留 Huber、排名、分支与路由监督，增加权重 0.2 的负相关性项；相关性分母加标准差尺度 0.02 的平滑项，常数预测仍有有限梯度。这是稳定化 Pearson 代理，不冒充无平滑的正式 IC。
- 时间权重仍为原训练日历年龄函数，但除以全训练有效日期的平均权重；单日损失再乘该日期权重，避免 batch 内相消。
- 一个完整日期仅更新一次优化器，步数明显少于 v1002。EMA 使用 `0.9999^(本次股票日数/64)`，按处理数据量调整衰减；优化器轨迹和有效 batch 仍改变，不声称等价于父版训练。

批量组织、损失和 EMA 单位共同构成一个设计，只解释整体效果。固定一个种子、一次正式运行，沿用验证 IC 和动态早停，不强行训练到某个耗时。重计算会增加计算成本，实际 GPU 显存、单轮耗时和总轮数由训练 session 记录；不以参数量不变承诺同速。
