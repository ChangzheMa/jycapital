## 已确认修改

### 1 取消模型内有效性掩码，保留池化时按全窗口汇总

状态：**已实现于 [v7a](../solutions/v7a/README.md)，待正式实验**。覆盖四个频率分支及后续模型计算中，所有按原始 Bar 是否有效而强制归零的同类操作；模型内部将全部时间位置视为有效。

| 位置 | 当前操作 | 修改要求 |
| --- | --- | --- |
| 输入投影与 GELU 后 | `F.gelu(self.project(x)) * valid` | 移除有效性乘法，保留计算结果 |
| 每个残差块的两次卷积子层末尾 | `self.dropout(F.gelu(x)) * valid` | 全部移除有效性乘法 |
| 残差相加后 | `(x + residual) * valid` | 保留相加结果，不再按原始有效性清零 |
| 均值池化 | `h.sum(dim=2) / valid.sum(dim=2).clamp_min(1)` | 改为 `h.mean(dim=2)`，全部时间位置求和后除以窗口长度 |
| 最后位置提取 | 按 `valid` 查找最后有效位置 | 改为 `h[:, :, -1]`，直接取窗口最后一个位置 |
| 每路分支输出处 | `pooled * (last_index >= 0)[:, None]` | 取消全空窗口的整路向量归零，允许保留网络计算出的分支表示 |

- 若模型其他位置存在相同语义的乘法、`where`、`masked_fill` 或条件返回零等处理，也纳入删除范围，允许原始 Bar 全无效的位置保留并传递隐藏状态。
- 单独实施本项时，保留 `last + mean` 拼接、`Linear(320,160)` 和 GELU；均值包含原始有效、无效及缺失槽位对应的全部隐藏值，分母固定为该分支的窗口长度，不再按原始有效数量计数。清理模型内不再使用的有效性辅助计算。
- 展平投影作为第 2 组独立实施；若同时采用，则由展平投影替代本项的全窗口 `last + mean` 汇总。

范围限于模型内部基于原始 Bar 有效性的隐藏状态屏蔽及汇总筛选。输入阶段的缺失值填零、组完整标志、时间编码与合法历史范围，以及标签有限性和输出数值检查均保留；Dropout 的随机丢弃不属于此项。

### 3 所有时序卷积采用左右对称边界复制

状态：**已实现于 [v7c](../solutions/v7c/README.md)，待正式实验**。覆盖四路全部 13 个残差块中的两次卷积，共 26 次；1×1 输入投影无需填充。

每次卷积复制当前隐藏特征的左右端点。步长为 1、核宽度 `k` 为奇数时，按实际膨胀率 `d` 计算每侧填充量 `padding = (k - 1) * d // 2`，使用 `F.pad(x, (padding, padding), mode="replicate")`，保持输出长度及残差相加的形状一致。

单独实施本组时，保留当前核宽 3 和膨胀率 1／2／4／8，左右各填充 1／2／4／8 个位置。与第 4 组同时采用时，膨胀率为 1，宽度 3／5／7／9 分别对应左右各填充 1／2／3／4 个位置。

该方案允许窗口内部双向计算，不再称为逐位置因果卷积。整个输入窗口仍只包含预测时点及以前已结束的 Bar；输出用于窗口末端的预测，中间隐藏位置不能解释为当时即可生成的预测。窗口长度、通道数和输入缺失值处理不变。

### 5 label 按截面标准化，预测不标准化，直接用 Huber 拟合

状态：**已实现于 [v7e](../solutions/v7e/README.md)，待正式实验**。将当前纯 Pearson IC 训练目标替换为标准化标签的 Huber 回归；原始标签仍使用官方 `vwap_return`。

对每个完整预测时间戳，以标签有限且时间边界合法的股票组成截面，按该截面的均值和总体标准差（`ddof=0`）计算目标：

\[
\mu_t=\frac{1}{n_t}\sum_i y_{t,i},\qquad
\sigma_t=\sqrt{\frac{1}{n_t}\sum_i(y_{t,i}-\mu_t)^2},\qquad
z_{t,i}=\frac{y_{t,i}-\mu_t}{\sigma_t}
\]

模型原始预测 \(s_{t,i}\) 直接与 \(z_{t,i}\) 比较，不对预测做截面去均值、除标准差或单位范数归一化：

\[
L_{\mathrm{train}}=\frac{1}{N}\sum_{t,i}\operatorname{Huber}_{\delta}(s_{t,i}-z_{t,i})
\]

其中 \(N\) 为合格截面的有限标签总数。验证／测试 Huber 采用截面等权汇总：

\[
L_t=\frac{1}{n_t}\sum_i\operatorname{Huber}_{\delta}(s_{t,i}-z_{t,i}),\qquad
L_{\mathrm{eval}}=\frac{1}{T}\sum_t L_t
\]

- 按用户于 2026-10-17（UTC+08:00）确认的修改，先按完整截面标准化目标，再沿用 v2/v3 的月内随机样本 batch 512，保留尾批，训练损失按样本均值。batch 内不重新标准化；相对 v7 的实验差异包含 batch 组织。标签不额外裁剪、排名或乘 100。标准化统计只用于构造监督目标，不能进入模型输入，推理不依赖未来标签及其统计量。
- Huber 同时约束预测与目标的数值差异；它替换纯 IC 损失，不混合 IC 项，也不保证每个预测截面的均值恰为 0、标准差恰为 1。
- 标签变换、损失调用、训练配置校验和损失日志同步调整；训练及验证的 Huber 损失不再使用当前 `loss = 1 - IC` 的一致性约束，IC 作为独立指标计算。
- 验证 IC 选模和统一动态早停沿用现有约定，IC／Rank IC 仍对原始官方标签计算。标准化目标上的 Huber 误差与原始收益尺度的 MSE／MAE 应分开解释；输出不直接视为收益预测。
- 本轮 Huber 阈值、退化截面及输出尺度按[实验固定设置](v7-ablation-experiments.md#本轮明确的边界设置)执行。历史 v1—v3 的 `delta=1` 对应收益先乘 100 的尺度，不能据此认定新方案的最优阈值。

该方案在 v1—v7 的现有正式运行中尚未验证；v3→v4 的 Huber 与纯 IC 比较未使用截面标准化标签，不能代替此方案的效果验证。历史方法与结果见 [v3](../solutions/v3/README.md) 和 [v4](../solutions/v4/README.md)。
