# 原始字段结构与盘口档位编码的研究依据

检索与核验日期：2026-10-22（UTC+08:00）。本轮以设计时已完成的本地最优 [v901](../solutions/v901/README.md#冻结结果与平台材料)为参照，考察原始输入的可学习组织方式，保留官方收益标签和既有评估协议。

## 本地依据

v901 的验证／测试 IC 为 0.087905／0.093509，Rank IC 为 0.088162／0.088342；当天多频输入、适中宽度和历史状态共享的组合有效。v701 的较宽网络未超过当时最优，但共享计算带来可接受的单轮成本。v801／v802 的当前跨股票模块未改善，下一版不继续堆叠集合头。

现有每频输入包含 36 个原始字段的两种既有标准化值，共 72 个数值通道，另有两个组完整标志与一个 Bar 可用标志。输入先经一个 75→隐藏维度的线性层，随后进入 GRU。这个线性层可以学习任意组合，但没有显式区分非盘口字段、五个盘口档位及不同类型的订单信息。按字段定义保留这类结构是一项待检验的网络归纳偏置，不是已有错误或性能瓶颈的证明。

## 方案设计

开启 v110x 字段结构编码系列，首版为 v1101，以 v901 的数据和共享 GRU 路径为基础。主要组合为：

- 按已知字段名将盘口数值重排为五个档位，每个档位含买／卖价格、数量、订单数的既有 z／c 表示；同档位使用共享小型投影，再学习档位间和通道间交互。非盘口原字段另走小型投影。
- 保留原始 75 通道的完整线性投影，并以初始尺度 0.1 添加结构分支，使网络仍可使用不受档位约束的表示；不增加手工价差、比例、汇总因子或样本筛选规则。
- 隐藏宽度从 160 提高到 192，保留原始时间分辨率、三频当天因果前缀、双头监督和 EMA。档位交互仅发生于同一 Bar 内，不跨股票或跨预测时点。

每个档位的数值经过原逐字段标准化，因此档位轴表达字段身份，不声称标准化后的价格仍单调。缺失标志作为输入继续传递，不能因盘口组不完整就清除其余有效字段。

整体方案仍一次正式训练，按验证 IC 选模；结合全部月份、Rank IC、换手代理与运行代价评价。保持 fast 推理及用户要求的简化转换检查，不把新表示设计等同于效果已改善。模型接口、实现检查和真实参数量以 v1101 的冻结配置及 readiness 为准。
