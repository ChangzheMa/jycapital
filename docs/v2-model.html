06

几个容易卡住的地方

点开一个问题，把前面几个概念再对齐一次。

147、60、64，分别在数什么？

147 是每根 Bar 输入的数值个数；60 是 1 分钟分支的历史 Bar 数；64 是网络内部每个时点的隐藏数值个数。比如 147 × 60 输入经过投影后变成 64 × 60，时间长度仍是 60。

36 个字段为什么先变成 72 个数？

每个字段保留 z 和 c 两个结果，所以是 36 × 2 = 72。四种频率分别做这件事。再加 72 个有效掩码和 3 个时间编码，才得到单根 Bar 的 147 个通道。

一个样本里有没有其他股票的数据？

网络收到的是目标股票自己的四段窗口。预处理计算 c 时，会使用同频、同时点股票池内各股票的 z 分布。因此目标股票的 c 包含截面相对位置。所有股票共享同一套网络参数，自身归一化统计量则按股票分别保存。

缺失的 Bar 会怎样？真实的 0 怎么办？

缺失 Bar 保留时间槽；切窗时缺失数值补 0，对应掩码也为 0。真实且有效的零值，其掩码为 1。若整根 Bar 的 72 个值都缺失，时间编码和隐藏状态也置零；若整个分支没有有效历史，该分支给融合头的 64 维表示为零向量。

“20 天历史”为什么和“60 根 Bar”不同？

窗口始终按各频率的固定 Bar 数构造：60、24、16、16。20 个日历天是历史允许的最大跨度。午休、隔夜和休市会增加日历跨度，缺失时间槽也占据固定窗口中的位置。

Bar 时间编码和预测时点编码有什么区别？

每根 Bar 有自己的结束时刻 sin、cos，以及到预测时点的归一化对数分钟差，共 3 个通道。预测时点另外有 sin、cos 两个数，它们与四个 64 维分支表示一起进入融合头：4 × 64 + 2 = 258。
