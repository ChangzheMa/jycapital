# 保留盘口档位状态的时空联合编码

## 从已有结果确定不同的机制

本轮先复核跨股票方向。v801／v802的晚期交互、v1501的市场时空组合和v2601的早期市场条件化均未优于对应有效单股票主干；不能继续仅替换注意力实现。它们的负结果不否定所有跨股票预测，但不足以支持下一次同类扩容。

当前v2401的字段投影把五档盘口先组织为独立token，在**同一根Bar内**交互，随后合并为一个192维向量，再交给日内GRU。这个映射没有被证明丢失信息，192维也不小于原输入维度；真正尚未直接检验的是：让每个档位的独立状态沿时间持续存在，并在递推层之间交换信息。

v601并未检验这个机制：它先混合全部75通道，再以时间卷积替换日内GRU，没有保留档位状态。其旧快照双集IC为0.076855／0.083834，负结果不能当作盘口时空组织已失败的证明。同样，v1101的单Bar结构加扩容组合只能支持保留字段身份，不能证明跨时间档位交互有效。

## v3201的可区分设计

新系列v320x研究日内状态的组织。以v2401为结构父版，从种子42重新初始化；使用修订数据，与旧父版不直接作分数差。保留77通道、三频完整历史、192维跨日GRU、价格历史读取、三频融合和原收益目标，不叠加尚未评估的v3001或v3101机制。

日内部分替换为六个持久字段节点：五个盘口档位加一个非盘口节点。每档包含原价格／数量／订单数的两视图及已有标志，非盘口节点包含原OHLC、成交量／额和标志；不构造价差、比例或新收益字段。

每个交易日依次执行：字段投影至64维 → 各节点共享的单向GRU → 同一Bar的六节点注意力与前馈交互 → 第二层节点共享单向GRU → 六节点拼接投影至192维。保留原75通道的直接线性路径。档位身份一直保留到第二层时间递推完成；单层节点状态总维度为384，参数在节点间共享。

时间递推在交易日边界重置，跨日依赖交给原跨日GRU。空间交互只发生在同一Bar，不做跨时间归一化，不用日末统计改写早时点。八个预测时点共享已有因果前缀，继续fast推理。该结构不恢复缺失的逐笔事件，也不声称档位数值经过既有标准化后仍是物理等距坐标。

## 判断与成本约束

这是一个新的日内编码结构组合，正式结果只能评价整体方案。保持原标签、训练采样、损失、EMA和验证选模；新快照内完整比较后才判定是否值得扩大。保留每频1／5／30分钟480／288／168槽位、训练64／推理128股票日与2GiB主机内存预留，复用新数据缓存。

节点共享的小GRU可以减少参数，却增加中间状态和递推次数，不能由参数较少宣称训练更快。验收需覆盖节点共享与独立计算的值／梯度一致、日边界隔离、空间依赖、缺失标志、八时点未来梯度、完整入口、恢复和fast路径。CPU实现检查不替代GPU默认批量预检或真实收益结果。
