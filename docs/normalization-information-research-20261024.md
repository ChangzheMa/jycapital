# 固定归一化参数与数量绝对尺度

[文档目录](README.md) · [既有归一化试验](causal-normalization-research-20261023.md) · [神经树方向](neural-tree-research-20261024.md)

研究与来源访问日期：2026-10-24，UTC+08:00。当前最优v2401验证／测试IC为0.107778／0.119352。v2001的共同盘口数量坐标与因果归一化组合已失败，不能将全部数量表示重新称作未探索方向。本轮补查成交量、金额及数量字段的绝对尺度能否低成本提供给模型，未读取收益标签或exposure。

## 当前表示与假设

冻结预处理按股票、频率和字段分别拟合`log1p`数量的均值与尺度，得到z；数量c再对z做截面标准化。模型直接取得z、c等视图，但没有直接接收各股票字段的固定均值和尺度。固定归一化在参数已知时可逆，不能据此声称原始信息全部不可恢复，也不能排除网络通过其他输入间接辨认尺度。

对于使用可信固定统计量的数量字段，理想算术下：

\[
\log(1+q)=\sigma_{s,f}\,z_{s,f}+\mu_{s,f}.
\]

这里的q是当前已闭合Bar提供的数量或金额，不是收益。实际父输入还经过FP32存储、FP16舍入及极值恢复，因此反变换只是原始对数数值的近似，不能标记为原始行情的逐位恢复。动态回退字段没有固定逆变换，本轮不拿全局均值冒充其真实参数。

该假设与v2001有明确边界：v2001已向模型提供二十个盘口数量的共同坐标，但替换了原c；成交量和金额仍使用原z/c。本轮考虑在完整保留父输入的前提下，补充固定数量尺度，尤其是此前未直接表达的成交量／金额绝对参考。是否有收益信息必须由正式实验回答。

## 固定训练样本结果

[分析脚本](../scripts/analyze-normalization-information.py)复用既有审计固定的2020—2023各六月样本，每年64股、排除首日后共16日、1,024股票日。读取303,101条三频Bar，仅含22个数量字段及对应已处理z；没有读取价格字段、验证／测试行情或标签。[完整记录](../experiments/normalization-information-audit-20261024.json)保存统计、样本与源码指纹。

样本内6,668,222个有效数量值均满足固定统计可信条件。下表统计按父版FP16编码及FP32极值恢复后，再用FP32均值／尺度反变换时的误差；为包含合法零值，相对误差以q+1作分母。

| 频率 | 成交量q+1相对误差99分位 | 成交金额q+1相对误差99分位 |
| --- | ---: | ---: |
| 1分钟 | 0.1388% | 0.1984% |
| 5分钟 | 0.0779% | 0.0859% |
| 30分钟 | 0.0868% | 0.1061% |

样本中没有正数量被恢复为非正数，但合法零值普遍产生微小舍入残差，不能据反变换后的严格等零判断原始零成交。所有结果只说明表示可实现，不代表收益可预测。

训练缓存股票的固定参数表很小：三频22字段的FP32均值、尺度与可信标志合计约1MiB，不需要新增整套行情数组。对数量单位提供不同参考是一个可检验的信息假设，不能因实现便宜就认定有效。训练缓存中也存在缺少固定统计的股票；后续实现须保留父输入并显式屏蔽不可逆的补充视图，不能删除样本或伪造参数。
