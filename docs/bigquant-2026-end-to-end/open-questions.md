## 仍需明确的官方要求

| 事项 | 未明确内容 |
| --- | --- |
| 官方数据边界 | 训练、公榜验证、私榜的精确日期，以及可训练数据范围；本地研究划分不代表官方分界 |
| 标签生成 | vwap_return 的代数公式、端点、零成交、异常处理和残差化阶段 |
| 正式模型运行 | 平台依赖、附件导入路径及隔离复现要求 |
| 采样与覆盖 | 私榜采样、缺失率分母、停牌／退市豁免、午休及末窗口规则 |
| 数据业务含义 | OHLC／复权因子缺失、负盘口量、交叉报价、空标签及供应商聚合方式 |
| 信息可获得时间 | 风格暴露、成分股及 ret 的可用时点 |
| 方法边界 | 收益变换、跨股票处理及风险暴露输入的具体许可 |
| 评测与资源 | 最终机型、总存储配额、IC 定义、年化、交易成本、中性化及压力场景参数 |
| 私榜与决赛 | 历史上下文、成绩与答辩排名的关系 |
| 本地授权 | 环境、存储及数据保留期限 |
| 提交次数 | 配置 max_submissions=1 的计数周期 |

e2e 的缩放、档位及 OHLC 缺失编码已有下载指南说明，见 [数据文档](data.md)。模型参数单文件按用户要求限制为 50 MB，见打包技能；其他未公布资源配额不据此推断。

Mock 接口通过、正式模型可运行和官方评分分别记录；本地模型结果不替代官方边界或许可。
