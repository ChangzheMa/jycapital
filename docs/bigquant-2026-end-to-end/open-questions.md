## 4. 配置字段不能过度解释

- `max_submissions=1`：配置中存在，但已读正文未解释是每日次数、候选数还是其他次数限制；本次未取得足以确认该含义的说明，不能写成“每天只能提交一次”。
- `enable_work_submission=false`：这是接口配置值，不足以推出比赛全部代码提交功能关闭。
- `status=preparing`：是读取时的配置状态；不能单凭它否定正文已开始的报名阶段。
- `range`：配置中还有一组与顶层 `start_date/end_date` 不一致的日期，语义未确认，不能当作正式总赛程。
- `__PARTITION__`：仅在辅助表 schema 中见到，未有业务说明，不应当作预测特征。
- 风格暴露表含 `ret`；没有确认可用时间与用途前，不能把它当作历史已知收益输入。
