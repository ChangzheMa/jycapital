# 同日后续收益标签的密集监督

[文档目录](README.md) · [持续研究约定](continuous-research.md) · [双集IC目标](ic-target-research-20261023.md)

研究与来源核验日期：2026-10-23，UTC+08:00。当前最优仍为 v1601，验证／测试IC为0.105526／0.116259。本方向独立于 v2401 的价格历史读取，直接以 v1601 为父版，不依赖待评测方案的未知效果。

## 为什么调整监督组织

v2101 的数量辅助任务在训练期优于持续性基准，但没有提高主收益IC；v1901 的标签后验也没有明显优于纯历史先验。本次不再增加数量任务、后验重建或分布头，而检验：**同一个因果历史前缀，能否通过分别预测多个后续时点的已有收益标签，学习对当前收益任务更有用的表示？**

这些标签仍是平台提供的 `vwap_return`，沿用完整截面标准化；不从价格重新计算任何未来收益，不把相邻标签求和或平均成新的主目标。后续标签仅用于训练损失，不进入模型输入、验证选模或平台推理。相邻标签负相关不意味着标签错误，也不意味着能凭当前输入预测后续标签。

## 训练数据覆盖

[只读脚本](../scripts/analyze-future-label-coverage.py)核对父缓存的标签、日期、股票和时点数组及其指纹，没有读取全量行情数值、验证／测试标签或 exposure。[冻结结果](../experiments/future-label-coverage-20261023.json)覆盖970个训练日、970,000个股票日，其中967,872个满足原主监督资格，原有效主标签为7,742,958个。

保持同一股票日内的查询资格，以较早预测时点为输入截止位置、严格后续时点的原标签为目标，可形成 **27,100,313个辅助监督对**。例如09:30前缀可以分别预测10:00至14:30所对应的原标签，14:30没有同日后续辅助任务。查询必须在当时股票池，未来目标缺失只屏蔽相应损失；不能根据未来标签筛选模型上下文。

## 单个组合方案的边界

保留父75通道、完整三频GRU历史、四专家主预测、排名辅助、日期权重与EMA。新增一个条件化辅助预测头，读取各时点的当前表示、目标时钟和相隔时点数；从同日28个严格前后时点组合分别预测后续标准化标签。该头不读取未来真值作为输入。

原主损失完整保留。辅助Huber损失先在每个当前查询的有效后续目标上平均，再按原日期权重对有辅助监督的查询平均；初版辅助总权重固定为0.5。这样不会仅因早时点拥有更多后续标签就给它更多辅助总权重。此权重是一次试验的预设，不进行扫描；不保证辅助梯度与主任务一致，需报告实际代价。

记录辅助训练损失及零预测基准，并按相隔时点数分别汇总，明确它们是raw训练统计。训练只需一次前向和一次反向，不采用v2101的两次梯度提取。原标签和成员索引按批配对，不新增全量目标数组或行情缓存。

正式推理只执行原主预测路径，不运行辅助头；默认fast、验证IC选模、完整测试、2GiB预留与一次正式训练均保持。新增头及辅助诊断状态须支持精确恢复。若失败，不自动调辅助权重或增大预测期限，也不把较低辅助损失解释为成功。

## 正式结果与后续判断

[v2501](../solutions/v2501/README.md#冻结结果)已完成：验证／测试IC为0.106972／0.118160，相对父v1601提高0.001446／0.001901，但低于新最优v2401。辅助查询Huber在最佳轮比零预测低约1.281%，实际配对与零基准经独立核验，仍只证明训练期任务可学习。八轮训练及验证增加约25.0%，未达到默认导出条件。

结果保留同日后续监督的小幅正向父版证据；不自动扫描辅助权重、不把它与v2401叠加后的效果视为可累加，也不将其作为大幅逼近双集0.25的充分方案。继续优先检验原始市场条件、遗漏字段及有独立机制依据的新方向。
