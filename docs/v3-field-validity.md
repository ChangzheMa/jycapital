## 第一层：原始数值是否合法

[log_values()](../solutions/v3/v3_preprocessing.py) 将输入转为 float64，先把 NaN、空值及正负无穷视为缺失，再按字段定义域判断。

| 类别 | 字段 | 有效条件 | 变换 |
| --- | --- | --- | --- |
| OHLC | `open, high, low, close` | 有限且严格大于 0 | `log(x)` |
| 五档盘口价格 | `ask_price1…5, bid_price1…5` | 有限且严格大于 0 | `log(x)` |
| 成交量、成交额 | `volume, amount` | 有限且大于等于 0 | `log1p(x)` |
| 五档委托量 | `ask_volume1…5, bid_volume1…5` | 有限且大于等于 0 | `log1p(x)` |
| 五档委托笔数 | `ask_num_orders1…5, bid_num_orders1…5` | 有限且大于等于 0 | `log1p(x)` |

因此，价格为 0 或负值无效，数量为 0 有效；负数量无效。非正价格和负数量改为 NaN，不用 0 冒充有效值。拟合统计量的 SQL 入口使用同样的有限性和定义域规则。

上述“无效”指是否能用于当前 `log(x)` 变换，不代表原始行情发生漏采。盘口价格为 0 可对应空档或集合竞价编码等正常状态，见 [业务解释](book-price-zero.md)。当前判定条件仍沿用 v2。

现有实现没有额外执行 OHLC 大小关系、盘口价格档位排序、成交额与成交量关系、极端值截断或人工特征筛选。这些条件没有被静默加入 v3。

按上述第一层条件的全量字段计数见 [原始字段无效值统计](raw-field-validity.md)。该统计不混入后续归一化与窗口判定。

## 第二层：z 与 c 能否得到有限值

原始值合法后，仍要检查归一化是否可用。

个股 z 优先使用该股票、该频率、该字段的完整训练期统计量。有效观测数至少为 30，总体标准差须大于 `1e-8`。不满足时，依次使用截至当前已结束 Bar 的扩展历史统计、训练期同频同字段全体股票统计；仍无可用统计量时保留缺失。全体股票字段恒定时用尺度 1，仍减训练均值。

c 对同频、同一 Bar 结束时刻股票池内的 z 做截面标准化。使用不晚于该时点的最后一份完整股票池快照，每个字段至少需要两个有效池内股票。数量不足时该 c 字段缺失；截面恒定时用尺度 1，仍是有效值。

归一化后的合法值可以为 0 或负值。此时仅检查有限性，不能再套用原始价格大于 0 的规则。归一化结果如果超出 float32 有限范围，现有预处理会报错，不能把此类溢出称为正常填零。

## 第三层：该 Bar 是否处于允许的输入历史

切窗只使用常规交易时段已结束的 Bar：上午 `(09:30,11:30]`、下午 `(13:00,15:00]`。每个原有时间槽必须满足：

- 网格位置存在，历史不是通过重复最早的 Bar 补足。
- Bar 结束时刻不晚于预测时点。
- 距预测时点不超过 20 个日历天。
- 该股票在对应时间槽的归一化字段有限；整根行情缺失时所有字段无效。

实际逐数值判定等价于：

```python
eligible = (positions >= 0) & (age >= 0) & (age <= 20 * 1440)
field_valid = np.isfinite(normalized_values) & eligible[..., None]
```

这里 `normalized_values` 是 72 个 z/c 值，不是原始行情。缺失槽保留原位置，跨午休、跨日和跨月保留已知历史；不读未来 Bar。

## v3 怎样汇总为两个标志

```python
non_book_complete = field_valid[..., non_book_indices].all(axis=-1)
book_complete = field_valid[..., book_indices].all(axis=-1)
values = np.where(field_valid, normalized_values, 0)
bar_observed = field_valid.any(axis=-1)
```

非盘口组检查六个原始字段的 z/c，共 12 个值；盘口组检查 30 个原始字段的 z/c，共 60 个值。全部有效才为 1，部分缺失和全部缺失均为 0。有效数值独立保留，缺失值独立补零，不清零整个组，也不排除样本。

组完整标志不能替代 `bar_observed`：两个组都不完整仍可能存在有效字段。v3 用已保留的 Bar sin/cos 编码恢复 `bar_observed`；全部字段缺失时这两个时间数均为 0，有任一有效字段时 sin/cos 不同时为 0。这样隐藏状态与池化保留 v2 的整根 Bar 有效性定义。

这两个输入标志只表达组完整性，不能还原逐字段缺失位置。它们不采用有效比例、不采用至少一个字段有效即为 1，也不触发整个样本的删除。
